## 一、方法总述

### 原文 1（与经典自编码器的唯一结构差异）

> *"Our masked autoencoder (MAE) is a simple autoencoding approach that reconstructs the original signal given its partial observation. Like all autoencoders, our approach has an encoder that maps the observed signal to a latent representation, and a decoder that reconstructs the original signal from the latent representation. Unlike classical autoencoders, we adopt an asymmetric design that allows the encoder to operate only on the partial, observed signal (without mask tokens) and a lightweight decoder that reconstructs the full signal from the latent representation and mask tokens."*

**直译：** 我们的掩码自编码器（MAE）是一种简单的自编码方法，从信号的**部分观测**重建原始信号。与所有自编码器一样，我们的方法有一个把观测信号映射到潜在表示的编码器，和一个从潜在表示重建原始信号的解码器。**不同于经典自编码器**的是，我们采用非对称设计：编码器只作用于部分的、被观测到的信号（不使用 mask token），而一个轻量级解码器从潜在表示连同 mask token 重建完整信号。

**解读：** 经典自编码器（包括 BERT 式做法）的 encoder 输入是"完整序列，其中缺失位置用 mask token 占位"；MAE 的 encoder 输入**只有可见 patch，连占位符都没有**。这一处差异是全部效率收益的来源，也是 MAE 区别于 BEiT/Context Encoder 等一切前作的关键结构决策。"asymmetric"（非对称）指：encoder 重、只看 25%；decoder 轻、看 100%。下游使用时 decoder 整个丢弃，只留 encoder。

## 二、四个组件逐一拆解

### 组件 1：掩码（Masking）

### 原文 2（采样策略）

> *"Following ViT [16], we divide an image into regular non-overlapping patches. Then we sample a subset of patches and mask (i.e., remove) the remaining ones. Our sampling strategy is straightforward: we sample random patches without replacement, following a uniform distribution. We simply refer to this as 'random sampling'. Random sampling with a high masking ratio (i.e., the ratio of removed patches) largely eliminates redundancy, thus creating a task that cannot be easily solved by extrapolation from visible neighboring patches (see Figures 2 - 4). The uniform distribution prevents a potential center bias (i.e., more masked patches near the image center). Finally, the highly sparse input creates an opportunity for designing an efficient encoder, introduced next."*

**直译：** 沿用 ViT [16]，我们把图像划分为规则、不重叠的 patch。然后采样一个 patch 子集，遮住（即移除）其余 patch。我们的采样策略很直接：按均匀分布、**不放回**地随机采样 patch，简称"随机采样"。高掩码比例（即被移除 patch 的比例）下的随机采样大幅消除了冗余，从而创造了一个**无法靠可见邻近 patch 外插轻易解决**的任务（见图 2–4）。均匀分布避免了潜在的中心偏置（即图像中心附近被遮 patch 更多）。最后，高度稀疏的输入为设计高效的编码器创造了机会，下文介绍。

**解读：** 三个设计点：
1. **随机、不放回、均匀分布**——没有 block-wise（BEiT 式大块遮罩）也没有 grid-wise（固定留一隔三）的花样。第 3 站 Table 1f 的消融会证明随机采样就是最优：block-wise 在 75% 时任务太难且重建模糊，grid-wise 任务太容易、表示质量差；
2. **"largely eliminates redundancy"**——呼应引言的信息密度分析：随机遮 75% 后，剩下 25% 的 patch 在空间上高度分散，几乎不存在连续可见区域，局部外插失去依据；
3. **"uniform distribution prevents center bias"**——一个容易忽略的细节：若按某些启发式（如优先遮边缘）采样，模型会学到一个固定的空间先验，任务被降维。均匀分布保证掩码图案对每个位置公平。

### 组件 2：编码器（MAE encoder）

### 原文 3

> *"Our encoder is a ViT [16] but applied only on visible, unmasked patches. Just as in a standard ViT, our encoder embeds patches by a linear projection with added positional embeddings, and then processes the resulting set via a series of Transformer blocks. However, our encoder only operates on a small subset (e.g., 25%) of the full set. Masked patches are removed; no mask tokens are used. This allows us to train very large encoders with only a fraction of compute and memory."*

**直译：** 我们的编码器是一个 ViT [16]，但只作用于可见、未被遮的 patch。与标准 ViT 一样，我们的编码器通过线性投影加位置嵌入来嵌入 patch，然后用一系列 Transformer 块处理所得集合。然而，我们的编码器只作用于完整集合的一个小子集（例如 25%）。被遮 patch 被移除；**不使用 mask token**。这使我们能够只用一小部分计算与内存来训练非常大的编码器。

**解读：** encoder 内部结构与标准 ViT **零改动**（linear projection → 加位置嵌入 → Transformer blocks），唯一的"改动"是输入集合变小了。这一点很重要：
- **架构零侵入**：任何现成的 ViT 实现都能当 MAE encoder，不需要定制算子；
- **计算量账**：patch 数降为 25%，注意力是平方复杂度，encoder 计算量约降为 1/16；线性部分降为 1/4。实际总体加速 3.7×（ViT-L，Table 2）；
- **位置嵌入照加**：25% 的可见 patch 各自带着自己的 2D 位置嵌入进入 encoder——位置信息由可见 patch 自带，不需要额外的位置推理。

### 组件 3：解码器（MAE decoder）

### 原文 4

> *"The input to the MAE decoder is the full set of tokens consisting of (i) encoded visible patches, and (ii) mask tokens. See Figure 1. Each mask token [14] is a shared, learned vector that indicates the presence of a missing patch to be predicted. We add positional embeddings to all tokens in this full set; without this, mask tokens would have no information about their location in the image. The decoder has another series of Transformer blocks."*

**直译：** MAE 解码器的输入是完整 token 集合，包含（i）编码后的可见 patch，以及（ii）mask token。见图 1。每个 mask token [14] 是一个**共享的、可学习的向量**，指示存在一个待预测的缺失 patch。我们把位置嵌入加到这个完整集合的所有 token 上；没有它，mask token 就不知道自己位于图像的哪个位置。解码器由另一系列 Transformer 块构成。

**解读：** decoder 的工作流程：encoder 输出的 25% 编码 token + 75% 个相同的可学习 mask token → 拼成 100% 的完整序列 → **此时才给所有 token 加位置嵌入**（注意：mask token 的位置信息完全靠这一步注入——"我该在哪重建出什么"由位置嵌入告诉它）→ 过一组 Transformer blocks 重建全图。
mask token 本身是**全图共享的一个向量**（与 BERT 的 [MASK] 相同设计），多样性完全来自位置嵌入。

### 原文 5（decoder 的灵活性与轻量性）

> *"The MAE decoder is only used during pre-training to perform the image reconstruction task (only the encoder is used to produce image representations for recognition). Therefore, the decoder architecture can be flexibly designed in a manner that is independent of the encoder design. We experiment with very small decoders, narrower and shallower than the encoder. For example, our default decoder has <10% computation per token vs. the encoder. With this asymmetrical design, the full set of tokens are only processed by the lightweight decoder, which significantly reduces pre-training time."*

**直译：** MAE 解码器**只在预训练时使用**，执行图像重建任务（只有编码器被用于产生识别任务的图像表示）。因此，解码器架构可以**独立于编码器设计**灵活地设计。我们实验了非常小的解码器，比编码器更窄、更浅。例如，我们的默认解码器每 token 计算量不到编码器的 10%。在此非对称设计下，完整 token 集合只由轻量级解码器处理，显著减少了预训练时间。

**解读：** 两个推论：
1. **decoder 是一次性用品**：预训练完即弃，下游任务只用 encoder。所以 decoder 的容量投入只影响"预训练时能把 encoder 表示逼到多高的语义层次"，不影响推理成本——这是敢于做非对称的根本理由；
2. **默认 decoder：8 块、宽 512**，而 ViT-L encoder 是 24 块、宽 1024——decoder 每 token 计算量只有 encoder 的 9%。即使 decoder 要处理 100% 的 token，它的总开销也只是整体计算的小头。第 3 站消融会给出 decoder 深/宽对 fine-tuning 与 linear probing 的不同影响。

### 组件 4：重建目标（Reconstruction target）

### 原文 6

> *"Our MAE reconstructs the input by predicting the pixel values for each masked patch. Each element in the decoder's output is a vector of pixel values representing a patch. The last layer of the decoder is a linear projection whose number of output channels equals the number of pixel values in a patch. The decoder's output is reshaped to form a reconstructed image. Our loss function computes the mean squared error (MSE) between the reconstructed and original images in the pixel space. We compute the loss only on masked patches, similar to BERT [14]."*

**直译：** 我们的 MAE 通过预测每个被遮 patch 的**像素值**来重建输入。解码器输出的每个元素是一个代表一个 patch 的像素值向量。解码器最后一层是一个线性投影，其输出通道数等于一个 patch 中的像素值个数。解码器输出被重塑（reshape）为一张重建图像。我们的损失函数在像素空间计算重建图像与原始图像之间的**均方误差（MSE）**。我们只在被遮 patch 上计算损失，与 BERT [14] 类似。

**解读：** 重建目标的三个要点：
1. **直接预测像素**：16×16×3 = 768 维向量/patch，decoder 末层线性投影输出 768 维，reshape 回图像。无需分词器、无交叉熵，与 BEiT（预测 dVAE 离散 token）形成路线分野；
2. **损失只算被遮的 75%**：可见 patch 不参与损失（Figure 2 题注也说明：因为没有损失约束，模型在可见 patch 上的输出质量反而较差——论文刻意不叠加可见 patch 展示，以完整暴露模型的重建行为）；
3. 原文脚注 1 交代了一个反直觉细节："Computing the loss only on masked patches differs from traditional denoising autoencoders [58] that compute the loss on all pixels. This choice is purely result-driven: computing the loss on all pixels leads to a slight decrease in accuracy (e.g., 0.5%)."（只算被遮 patch 不同于经典 DAE 的全像素损失；这一选择纯粹由结果驱动——全像素损失会让精度下降约 0.5%）。可见 patch 的损失会分散模型对"难的部分"（被遮区域）的注意力。

### 原文 7（per-patch 归一化变体）

> *"We also study a variant whose reconstruction target is the normalized pixel values of each masked patch. Specifically, we compute the mean and standard deviation of all pixels in a patch and use them to normalize this patch. Using normalized pixels as the reconstruction target improves representation quality in our experiments."*

**直译：** 我们还研究了一个变体，其重建目标是每个被遮 patch 的**归一化像素值**。具体地，我们计算一个 patch 内所有像素的均值与标准差，并用它们归一化该 patch。在我们的实验中，使用归一化像素作为重建目标提升了表示质量。

**解读：** per-patch 归一化（每个 patch 减自己的均值、除自己的标准差）的效果是**增强局部对比度**，把重建任务从"猜亮度/色调"推向"猜纹理/结构"——亮度、色调这类低层全局信息被归一化掉之后，模型必须靠结构信息重建。第 3 站 Table 1d：归一化像素 fine-tuning 85.4 vs 未归一化 84.9，linear probing 73.9 vs 73.5；Table 3 的最终旗舰结果（87.8%）使用的就是归一化像素。这个一行代码的改动是 MAE 里投入产出比最高的技巧之一。

### 组件 5：无稀疏算子的简单实现

### 原文 8

> *"Our MAE pre-training can be implemented efficiently, and importantly, does not require any specialized sparse operations. First we generate a token for every input patch (by linear projection with an added positional embedding). Next we randomly shuffle the list of tokens and remove the last portion of the list, based on the masking ratio. This process produces a small subset of tokens for the encoder and is equivalent to sampling patches without replacement. After encoding, we append a list of mask tokens to the list of encoded patches, and unshuffle this full list (inverting the random shuffle operation) to align all tokens with their targets. The decoder is applied to this full list (with positional embeddings added). As noted, no sparse operations are needed. This simple implementation introduces negligible overhead as the shuffling and unshuffling operations are fast."*

**直译：** 我们的 MAE 预训练可以高效实现，而且重要的是，**不需要任何专门的稀疏算子**。首先，为每个输入 patch 生成一个 token（线性投影加位置嵌入）。然后，随机**打乱**（shuffle）token 列表，并按掩码比例删除列表尾部的部分。该过程产生给编码器的小 token 子集，且等价于不放回地采样 patch。编码后，把一组 mask token 追加到编码 patch 列表之后，并**反打乱**（unshuffle，逆转随机打乱操作）这个完整列表，使所有 token 与其目标对齐。解码器作用于这个完整列表（加上位置嵌入）。如上所述，不需要稀疏算子。这个简单实现引入的开销可忽略，因为打乱与反打乱操作很快。

**解读：** 这段是工程要点。朴素实现"只对 25% 的 patch 跑 encoder"需要稀疏注意力或 gather/scatter 定制算子；MAE 用 **shuffle + 截断** 把稀疏选择变成普通张量操作：
1. 全部 patch 先投影成 token（含位置嵌入）；
2. 随机打乱 token 顺序 → 砍掉尾部 75% → 剩 25% 进 encoder（对 GPU 就是普通 dense batch，零定制算子）；
3. encoder 输出拼上 mask token → 按原顺序反打乱 → decoder 处理。

"shuffle 等价于不放回均匀采样"是这个技巧的数学依据。这与 DETR 的"几百行代码"卖点一脉相承：ViT 分支的工作普遍把"无定制算子"当作方法学的加分项。

## 三、预训练与评估的完整流程（Figure 1 串讲）

按 Figure 1 与 §3 的描述，整个流程为：

| 阶段 | 操作 | 细节 |
|---|---|---|
| ① patch 化 | 224×224 图像切 16×16 patch → 14×14 = **196 个 patch** | 与 ViT 相同 |
| ② 采样掩码 | 均匀不放回采样 75% 遮住 → 剩 **49 个可见 patch** | Figure 2 题注给出 80% 掩码时剩 39 个 |
| ③ encoder | ViT 处理 49 个可见 patch（无 mask token） | 加 2D 正弦位置嵌入 |
| ④ 拼接 | 147 个共享可学习 mask token 补位 → 反 shuffle 复原空间顺序 | mask token 的位置信息靠位置嵌入注入 |
| ⑤ decoder | 轻量 Transformer（8 块、512 宽）处理 196 token，输出每 patch 768 维像素向量 | 位置嵌入在此处加入 |
| ⑥ 损失 | MSE，只算被遮的 147 个 patch | 归一化像素变体更优 |
| ⑦ 下游 | **decoder 丢弃**，encoder 对完整图像提取特征，接 fine-tuning / linear probing / 检测、分割 | encoder 架构与 ViT 完全一致 |

预训练超参（附录 Table 8）：AdamW，base lr 1.5e-4（线性缩放规则 lr = base × batchsize/256），batch size 4096，weight decay 0.05，cosine 衰减 + 40 epoch warmup，增广仅 RandomResizedCrop，xavier uniform 初始化，**不用** color jitter / drop path / 梯度裁剪。

## 四、第 2 站小结

| 维度 | 内容 |
|---|---|
| 与经典自编码器的差异 | encoder 只处理可见 patch（无 mask token）；decoder 轻量且预训练后即弃 |
| 掩码采样 | 均匀、不放回、随机；75% 比例消除空间冗余、防中心偏置；消融证明优于 block-wise / grid-wise |
| Encoder | 标准 ViT 零改动，仅输入变为 25% patch；位置嵌入照加 |
| Decoder | 输入 = 25% 编码 token + 75% 共享可学习 mask token；全集合加位置嵌入；默认 8 块、512 宽（约 encoder 每 token 9% 计算量） |
| 重建目标 | 被遮 patch 的像素值，MSE；损失只算被遮 patch（全像素损失反而 -0.5%）；per-patch 归一化像素更优（+0.5 ft / +0.4 lin） |
| 实现技巧 | shuffle → 截断 → encode → 拼 mask token → unshuffle，无需稀疏算子 |
| 评估协议 | 丢弃 decoder，encoder 接 fine-tuning / linear probing / 下游迁移 |
| 预训练配方 | AdamW、base lr 1.5e-4、batch 4096、wd 0.05、仅 RandomResizedCrop、800–1600 epoch |

### 自检小问题

1. MAE encoder 的输入与 BERT / BEiT 式"mask token 占位"方案的本质区别是什么？这一区别带来什么计算收益？
2. mask token 是什么（形状、是否共享）？它的位置信息从哪里来？
3. 为什么均匀随机采样要避免"中心偏置"？随机采样相比 block-wise / grid-wise 的优势各是什么（结合任务难度）？
4. 重建损失为什么只算被遮 patch？全像素损失会怎样？
5. per-patch 归一化像素为何能提升表示质量？它归一化掉了什么、保留了什么？
6. "shuffle + 截断"实现为什么等价于不放回均匀采样？它省掉了什么工程负担？
7. decoder 为什么可以比 encoder 小得多而不影响下游性能？
