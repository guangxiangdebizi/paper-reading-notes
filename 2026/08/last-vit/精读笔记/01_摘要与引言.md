## 一、摘要逐句精读

### 原文 1（问题定性：artifact 跨范式普遍存在，机理未明）

> *"Vision Transformers (ViTs), when pre-trained on large-scale data, provide general-purpose representations for diverse downstream tasks. However, artifacts in ViTs are widely observed across different supervision paradigms and downstream tasks. Through systematic analysis of artifacts in ViTs, we find that their fundamental mechanisms have yet to be sufficiently elucidated."*

**直译：** Vision Transformer（ViT）在大规模数据上预训练后，为多样的下游任务提供通用表示。然而，ViT 中的 artifact（伪影/伪迹）在不同的监督范式与下游任务上被广泛观察到。通过对 ViT 中 artifact 的系统分析，我们发现其根本机制**尚未得到充分阐明**。

**解读：** 摘要开篇先把冲突摆出来：ViT 作为通用特征提取器的地位没有问题，但其内部表示在密集预测场景下反复出现异常响应（artifact），且这些异常在标签监督、文本监督、自监督三种范式下都有记录。关键判断是第二句——现有工作只是各自记录了自己范式下的现象（Registers 记录了自监督 ViT 的 high-norm token，CLIPSelf 记录了文本监督 ViT 的密集对齐失败，等等），**没有人给出跨范式的统一机理**。这正是本篇的切入点：不是再造一个针对单一范式的修补方法，而是先把机理讲清楚。

### 原文 2（核心结论：懒惰聚合）

> *"In this paper, through systematic analysis, we conclude that these artifacts originate from a lazy aggregation behavior: ViT uses semantically irrelevant background patches as shortcuts to represent global semantics, driven by global attention and Coarse-grained semantic supervision."*

**直译：** 本文通过系统分析得出结论：这些 artifact 源于一种**懒惰聚合行为**（lazy aggregation behavior）：ViT 把语义无关的背景 patch 当作表示全局语义的捷径，这一行为由**全局注意力**与**粗粒度语义监督**共同驱动。

**解读：** 全文的中心论点一句话讲完，包含三层信息：
1. **行为命名**：lazy aggregation——聚合（CLS token 汇总全图信息）本身是 ViT 的正常工作方式，问题在于聚合的对象选错了：模型选了语义无关的背景 patch；
2. **后果形式**：背景 patch 成为"表示全局语义的捷径"（shortcuts）。捷径意味着优化上是省力的——背景区域在自然图像中面积占比大、数量占优，拿它们承载全局信号比精确定位前景再聚合更"省事"；
3. **两个驱动因素**：全局注意力（提供了信息扩散的通道）+ 粗粒度语义监督（图像级标签，只约束全图一个向量，不提供 patch 级空间约束）。第 2 站会用两个受控实验分别验证这两个因素。

### 原文 3（解法与结果：选择性聚合，12 个 benchmark 一致提升）

> *"Our solution selectively integrates patch features into the CLS token, reducing the influence of background-dominated shortcuts and consistently improving performance across 12 benchmarks under label-, text-, and self-supervision. We hope this work offers a new perspective on ViT behavior."*

**直译：** 我们的解法**选择性地**把 patch 特征整合进 CLS token，降低背景主导捷径的影响，并在标签、文本、自监督三种范式下的 **12 个 benchmark** 上一致提升性能。我们希望本工作为理解 ViT 行为提供一个新视角。

**解读：** 解法的关键词是 **selectively**（选择性）——对照 ViT 的标准做法（对全部 patch 做全局平均池化，或让一个 CLS query 无差别注意全部 token），本文的 CLS token 只从经过筛选的 patch 子集聚合信息。筛选发生在预训练期，不改变网络架构，这是与既有修补类工作的本质区别（相关工作一节会展开对比）。"12 个 benchmark 三种监督范式一致提升"是方法普适性的直接证据，第 4 站逐表核对。

## 二、引言逐句精读

### 原文 4（背景：ViT 的地位与三种监督范式）

> *"Vision Transformers (ViTs) [7] have become the de facto standard for image recognition [6, 13, 22-24, 40]. More importantly, they serve as general-purpose feature extractors across various specific vision tasks [4, 9, 12, 33, 45], functioning as a frozen foundation model pre-trained on large-scale data to embed images into feature representations, enabled by their scalability in data and model size. More broadly, this generic ViT feature extractor can adapt to various supervision methods during pre-training, with different approaches exhibiting characteristics particularly suited to diverse downstream tasks. Specifically, supervised methods--such as training ViTs with fully-supervised classification labels or text-supervised image-text pairs (e.g., in models like CLIP [27])--produce dense features for open-vocabulary tasks, and function as visual encoders for large vision-language models (LVLMs) [20]. Alternatively, self-supervised methods [1, 2, 25], particularly the DINO [1] model trained solely on images, demonstrate the potential for object and part discovery, making them applicable to unsupervised segmentation tasks [31]."*

**直译：** Vision Transformer（ViT）[7] 已成为图像识别的事实标准 [6, 13, 22-24, 40]。更重要的是，它们在各种具体视觉任务中充当**通用特征提取器** [4, 9, 12, 33, 45]，作为在大规模数据上预训练的冻结基础模型把图像嵌入为特征表示，这得益于其在数据与模型规模上的可扩展性。更广泛地，这种通用 ViT 特征提取器在预训练期间可以适配各种监督方法，不同方法表现出特别适合不同下游任务的特性。具体而言，监督方法——例如用全监督分类标签或文本监督的图文对（如 CLIP [27] 类模型）训练 ViT——产生用于开放词汇任务的密集特征，并充当大型视觉语言模型（LVLM）[20] 的视觉编码器。另一条路是自监督方法 [1, 2, 25]，尤其是仅在图像上训练的 DINO [1] 模型，展现出目标与部件发现的潜力，使其适用于无监督分割任务 [31]。

**解读：** 引言第一段在做三件事：
1. 确认 ViT 的角色已从"分类器"升级为"冻结的通用特征提取器"（frozen foundation model）——这正是 artifact 问题变得重要的前提：当特征被密集任务（分割、检测、定位）直接消费时，patch 级表示的质量才成为硬约束；只做图像分类的话，CLS token 从背景聚合还是从前景聚合根本无关紧要；
2. 把预训练监督方式整理成三类：**标签监督**（ImageNet 分类标签）、**文本监督**（CLIP 式图文对）、**自监督**（DINO，仅图像）；
3. 每类各给出其下游定位：监督/文本监督 → 开放词汇密集特征、LVLM 视觉编码器；自监督 → 目标/部件发现、无监督分割。

这三种范式各自的典型 artifact 现象下一段就会逐一列出。本篇所有实验也严格按这三类组织（第 4 站的 Tables 3-9 分别对应三种范式）。

### 原文 5（三种范式各自的 artifact 记录）

> *"However, recent studies uncover puzzling dense-feature artifacts in ViTs when applied to downstream tasks requiring dense features. For instance, DINO [43] demonstrates that label-supervised ViTs suffer from an attention deficit [26], while CLIPSelf [37] observes that text-supervised ViTs fail to produce dense image features that are accurately aligned with textual cues in open-vocabulary tasks. Meanwhile, Register [5] reveals that self-supervised ViTs generate artifacts in the attention maps, commonly referred to as high-norm tokens, which adversely affect object localization tasks [31]."*

**直译：** 然而，近期研究揭示了 ViT 应用于需要密集特征的下游任务时令人困惑的密集特征 artifact。例如，DINO [43] 表明**标签监督**的 ViT 存在注意力缺失（attention deficit）[26]；CLIPSelf [37] 观察到**文本监督**的 ViT 无法产生与文本线索准确对齐的密集图像特征（在开放词汇任务中）；同时，Register [5] 揭示**自监督** ViT 在注意力图中产生 artifact，通常被称为 high-norm token，它们对目标定位任务 [31] 有不利影响。

**解读：** 这段把三种范式下的异常现象逐一对应到具体文献，构成"artifact 跨范式普遍存在"的证据链：
- **标签监督**：attention deficit（注意力缺失）——DETR-DETR 检测器 DINO [43] 发现用标签监督 ViT 做检测骨干时注意力行为异常，[26]（SimPool）对该现象有专门讨论；
- **文本监督**：密集特征与文本对齐失败——CLIPSelf [37] 的记录，CLIP ViT 的 patch 特征与文本的相似度图噪声大、定位差，尽管分类很强；
- **自监督**：high-norm token——Registers [5] 的记录，DINOv2 特征图中出现少数范数异常高的 token，破坏目标定位（LOST [31] 这类无监督定位方法受其干扰）。

注意三个现象表面形态完全不同（注意力缺失 / 对齐失败 / 高范数 token），这正是此前没人把它们归为同一问题的原因。本篇的论点是：它们是**同一根源在不同监督信号下的不同显形**。

### 原文 6（统一解释的必要性：既有方法各治一隅）

> *"These phenomena suggest a common underlying issue in ViTs, merely manifesting differently under various supervision paradigms [1, 14, 34]. In our preliminary exploration, we found that no single method [5, 36, 44] could comprehensively address these phenomena. This result suggests that our understanding of ViTs remains incomplete, even though they have been studied for roughly half a decade [7]. Given that many issues may stem from a shared mechanism, a unified solution is desirable. In this paper, we undertake a first-principles investigation - systematically defining, analyzing, and addressing the different types of artifacts observed in ViTs from the ground up."*

**直译：** 这些现象暗示 ViT 存在一个共同的潜在问题，只是在各种监督范式下以不同形式显现 [1, 14, 34]。在我们的初步探索中，发现**没有任何单一方法** [5, 36, 44] 能够全面处理这些现象。这一结果表明，尽管 ViT 已被研究约五年 [7]，我们对它的理解仍不完整。鉴于许多问题可能源于共享机制，一个统一的解法是符合期望的。本文开展一项**第一性原理的考察**——从零开始系统地定义、分析并处理 ViT 中观察到的各类 artifact。

**解读：** 这段是方法论宣言，有三个要点：
1. **初步探索的负面结果**：[5] = Registers（register token）、[36] = S-CLIP（改自注意力）、[44] = MaskCLIP（直接读注意力权重做分割）——三个代表性修补方法没有一个能同时覆盖三种范式的现象。这个负面结果支撑"机理未明"的判断：如果机理清楚，就不会出现"各治一隅"的局面；
2. **"理解不完整"的定性**：ViT 自 2020 年发布已被研究约五年，但其表示形成机制仍有盲区——这为"先诊断、后开方"的研究路径提供了正当性；
3. **first-principles（第一性原理）**：对应论文的实际结构——先给统一定义（Patch Score，§4.1），再做系统分析（§4.2-4.4 的空间与时间两个维度 + 两因素隔离验证），最后才提出方法（§5）。诊断占了全文一半以上的篇幅。

### 原文 7（统一定义：Patch Score）

> *"To establish a unified definition for these phenomena across different paradigms, we introduce the Patch Score--the similarity between patch features and the CLS token, which encapsulates an image's global semantics--thereby assessing local semantic consistency relative to the global representation, independent of the training paradigm. The intuition behind Patch Score is that for ViT under different supervision, the training objective aims to align the CLS feature with supervisory signals (e.g., labels or text); any misalignment in dense features results in increased Patch Scores in non-foreground regions, as shown in Fig. 1."*

**直译：** 为给这些跨范式现象建立统一定义，我们引入 **Patch Score**——patch 特征与 CLS token 之间的相似度，其中 CLS token  encapsulate（承载）一张图像的全局语义——从而评估相对于全局表示的**局部语义一致性**，且独立于训练范式。Patch Score 背后的直觉是：对于不同监督下的 ViT，训练目标都是把 CLS 特征与监督信号（如标签或文本）对齐；密集特征中的任何错位都会导致非前景区域的 Patch Score 升高，如图 1 所示。

**解读：** Patch Score 是全文的第一个核心工具，设计上有两个关键决策：
1. **为什么能跨范式统一**：三种监督范式的训练目标都可以表述为"把 CLS 特征对齐到监督信号"——标签监督下 CLS 接分类头对齐类别 one-hot，文本监督下 CLS 对齐文本嵌入（CLIP 对比损失），自监督下 CLS 对齐教师网络的输出（DINO 自蒸馏）。因此"patch 特征与 CLS 的相似度"这把尺子在三种范式下量的是同一种东西：**局部 patch 与全局语义的对齐程度**，不需要知道监督信号具体是什么；
2. **诊断逻辑**：如果一切正常，高分 patch 应集中在前景目标上（前景才承载与类别/文本相关的语义）；如果非前景区域（背景）出现高分，就说明全局语义被错误地编码进了背景——这正是 Fig 1 中间与右侧可视化展示的现象。

对 ConvNet 的适配（用 GAP 特征充当隐式 CLS）在第 2 站 Eq.3 处展开，这是 Table 1 能做 ViT/ResNet 对照的原因。

### 原文 8（量化指标：Point-in-Box 与核心发现）

> *"To quantitatively assess artifacts in Patch Scores, we propose the Point-in-Box (PiB) metric, which evaluates whether the patch with the highest score lies within the annotated foreground region. As shown in Fig. 1 and Tab. 1, we find that across different supervision settings, ViTs assign higher Patch Scores to background patches and achieve much lower PiB compared with ConvNets [11]."*

**直译：** 为定量评估 Patch Score 中的 artifact，我们提出 **Point-in-Box（PiB）** 指标，它评估得分最高的 patch 是否落在标注的前景区域内。如图 1 与表 1 所示，我们发现在不同监督设置下，与 ConvNet [11] 相比，ViT 给背景 patch 赋予更高的 Patch Score，且 PiB **显著更低**。

**解读：** PiB 是全文的第二个核心工具，把 Fig 2a 那种"分布上背景占高分尾部"的定性观察压缩成一个可追踪的标量：
- **构造**：取 ImageNet 验证集中带单一目标标注的图像，检查每张图 Patch Score 最高的那个 patch 是否落在前景标注框内，统计比例；
- **选单一目标图**的原因：避免多目标图中"哪个前景算正解"的歧义；
- **核心发现**：ViT 各范式的 PiB 全面低于对应的 ResNet（Table 1：标签监督 42.7 vs 68.4；DINO 自监督 45.3 vs 71.1；OpenCLIP 39.8 vs 53.9），且给 ViT 加 register token 后 PiB 不升反降（42.7 → 41.5）——后者直接指向"high-norm token 不是根因"的论断，第 2 站展开。

### 原文 9（术语约定：artifact 的操作性定义）

> *"For clarity and simplicity, unless explicitly stated otherwise, the term 'artifacts' in the following text specifically refers to semantically irrelevant background tokens that erroneously yield high Patch Scores."*

**直译：** 为清晰与简洁起见，除非特别说明，下文中"artifact"一词特指**错误地产生高 Patch Score 的、语义无关的背景 token**。

**解读：** 这句操作性定义值得单独记录。Registers 原文中 artifact 指特征图上的异常高响应区，范围较宽；本篇把 artifact 收窄为一个可度量的对象——"高 Patch Score 的背景 token"。这个收窄有两个作用：① 把讨论锚定在 Patch Score 这把统一尺子上，避免与 high-norm、attention spike 等表面现象混谈；② 为后文"消除 artifact"提供明确的验收标准（高分 patch 回到前景、PiB 上升）。

### 原文 10（假设因素一：粗粒度监督 → 背景证据捷径）

> *"Natural images inherently contain many background patches that are irrelevant to the primary object. With only image-level supervision, the model lacks spatial guidance and thus tends to encode global semantics via background evidence (lazy aggregation). Empirically, removing the top 50% highest-scoring patches in a pre-trained ViT has negligible impact on ImageNet accuracy (Fig. 2), corroborating this reliance."*

**直译：** 自然图像天然包含许多与主目标无关的背景 patch。在只有图像级监督的情况下，模型缺乏空间引导，因而倾向于通过背景证据来编码全局语义（懒惰聚合）。经验上，移除预训练 ViT 中得分最高的前 50% patch 对 ImageNet 精度**影响可以忽略**（图 2），印证了这种依赖。

**解读：** 假设的第一个因素：**粗粒度语义监督**。逻辑链：
1. 自然图像中背景 patch 数量上占多数（一张图里前景目标常常只占一小块区域）；
2. 图像级标签只告诉模型"这张图是金毛犬"，不告诉它"哪些 patch 是金毛犬"——模型没有空间引导；
3. 于是模型在优化压力下选择统计上最省力的路径：背景 patch 数量多、与图像级标签也存在稳定的数据集级共现关系（某类目标常出现在某类背景中），拿背景承载全局语义即可把分类损失降下去；
4. **经验证据**：把得分最高的 50% patch 全部移除，分类精度几乎不变（第 2 站 Fig 2b 实测：移除到 70% 都不伤精度，ViT-B/16 甚至 +1.2%）——最高分的那批 patch 对分类几乎不提供独占信息，说明它们承载的"全局语义"本质上是冗余的背景信号。

### 原文 11（假设因素二：全局依赖 → 语义扩散通道）

> *"Global dependencies allow ViT to exploit these extraneous background patches as shortcuts to represent global semantics. In the absence of patch-level annotations, ViTs may adopt a lazy aggregation by diffusing small foreground semantics to background at the beginning of training (Fig. 3). We validate that reducing global dependencies indeed mitigates artifact phenomena (Tab. 2)."*

**直译：** 全局依赖使 ViT 能够利用这些无关的背景 patch 作为表示全局语义的捷径。在缺乏 patch 级标注的情况下，ViT 可能在训练初期就采取懒惰聚合——把小范围的前景语义**扩散**到背景上（图 3）。我们验证了减少全局依赖确实能缓解 artifact 现象（表 2）。

**解读：** 假设的第二个因素：**全局注意力提供的信息扩散通道**。逻辑链：
1. ViT 每一层都是全局自注意力——任意两个 patch 之间都有直接的信息交换通道；
2. 前景目标在图像上往往只占少数 patch（"small foreground semantics"），如果模型必须从这几个前景 patch 聚合语义，优化路径较窄；而全局注意力允许前景语义在训练早期就被复制、扩散到大量背景 patch 上，之后 CLS token 从这些背景 patch 聚合，等效于间接读到了前景语义，但聚合点对噪声、遮挡更"稳健"（因为样本量大）；
3. 这个扩散过程在**训练初期**就开始（Fig 3 是时间维证据，第 2 站展开）；
4. **验证路径预告**：如果全局依赖是必要条件，那么人为限制注意力范围（换成窗口注意力）应能缓解 artifact——Table 2 的受控实验证实了这一点（PiB 50.1 → 59.8），代价是分类精度下降（72.3 → 63.9）。

两个因素合起来的完整表述：**粗粒度监督制造了走捷径的动机，全局注意力提供了走捷径的通道**。

### 原文 12（解法预告与命名）

> *"Building on this interpretation, we further validate our hypothesis by proposing a straightforward solution to eliminate these artifacts: By regulating the influence of background patches during pre-training, we encourage ViTs to focus on foreground semantics. Specifically, the model learns to estimate the contribution of each token (Sec. 5.1) and selectively integrate informative patch features into the CLS token to strengthen foreground representation. As shown in Fig. 5, ViTs automatically shift their attention to foreground objects, aligning high-scoring patches with the foreground as these ratios are appropriately increased. Once this lazy aggregation is mitigated, our approach - termed LaSt-ViT (LazyStrike ViT)- eliminates Patch Score artifacts across all types of supervision. It effectively addresses both the high-norm token issue and feature misalignment. Notably, after applying our method, ViTs exhibit improved emergent semantic segmentation properties [43] consistently across different pre-training paradigms."*

**直译：** 基于这一解释，我们通过提出一个直接的解法来进一步验证假设、消除这些 artifact：通过在预训练期间**约束背景 patch 的影响**，促使 ViT 聚焦前景语义。具体地，模型学习估计每个 token 的贡献（§5.1），并选择性地把有信息量的 patch 特征整合进 CLS token 以增强前景表示。如图 5 所示，随着这些比例被适当提高，ViT 自动把注意力转向前景目标，使高分 patch 与前景对齐。一旦懒惰聚合被缓解，我们的方法——称为 **LaSt-ViT（LazyStrike ViT）**——消除所有监督类型下的 Patch Score artifact。它同时有效处理 high-norm token 问题与特征错位问题。值得注意的是，应用该方法后，ViT 在不同预训练范式下一致地表现出改进的**涌现语义分割性质** [43]。

**解读：** 这段预告了方法与其验证逻辑，有四个要点：
1. **方法介入时机是预训练期**（regulating ... during pre-training）——不是训完再修，而是训练过程中就改变聚合规则；
2. **方法的双向作用**：模型先学一个"每个 token 贡献度"的估计（§5.1 的稳定度分数），再据此选择性地构造 CLS token；
3. **假设-方法闭环**：方法本身也是假设的验证工具——如果 artifact 真的源于背景捷径，那么切断背景对 CLS 的贡献后模型应当被迫转向前景聚合，Fig 5 的可视化证实了这一点（高分 patch 转向前景、且其数量随图中前景证据量增减）；
4. **副产品**：high-norm token 现象被顺带消除（说明 high-norm 只是 lazy behavior 的后期表象而非根因），且"分割涌现"（此前被认为是自监督专属的性质，[43] 指 DINO 论文记录的 emergent properties）在监督范式下也出现。"LaSt-ViT / LazyStrike" 的命名直指 lazy aggregation——"strike" 即对该行为的打击。

### 原文 13（四条贡献）

> *"Contributions. (1) We systematically analyze the root cause of artifacts in ViTs via Patch Score and Point-in-Box (PiB), revealing a background-dominant bias that emerges early and persists. (2) We provide a hypothesis linking Coarse-grained semantic supervision and global dependencies to lazy aggregation--a shortcut behavior where ViTs rely on background patches to encode global semantics instead of attending to true foreground regions. (3) We propose LaSt-ViT, a simple, frequency-aware selective aggregation scheme that anchors the CLS token to foreground regions. (4) We demonstrate consistent gains across 12 benchmarks including object discovery, semantic/instance segmentation, and open-vocabulary detection."*

**直译：** 贡献。（1）我们通过 Patch Score 与 Point-in-Box（PiB）系统分析 ViT 中 artifact 的根因，揭示出一种**早期出现且持续存在**的背景主导偏差。（2）我们给出一个假设，把粗粒度语义监督与全局依赖同懒惰聚合联系起来——即 ViT 依赖背景 patch 编码全局语义、而非关注真实前景区域的捷径行为。（3）我们提出 LaSt-ViT，一种简单的、**频率感知**的选择性聚合方案，把 CLS token 锚定到前景区域。（4）我们展示了在 12 个 benchmark 上的一致增益，涵盖目标发现、语义/实例分割与开放词汇检测。

**解读：** 四条贡献与全文结构一一对应：（1）→ §4.1-4.2（度量定义 + 空间/时间分析，对应第 2 站）；（2）→ §4.3-4.4（两因素隔离验证，对应第 2 站）；（3）→ §5（LazyStrike 方法，对应第 3 站；"frequency-aware" 点明筛选用的是频域手段——通道维傅里叶低通）；（4）→ §6（三范式 12 benchmark 实验，对应第 4 站）。

## 三、相关工作速览（§2，两条脉络的定位）

论文 §2 按 artifact 出现的监督范式分两段梳理既有工作：

### 1. 文本监督 ViT 的 artifact（CLIP 系）

> *"MaskCLIP [44] first showed that CLIP features can yield zero-shot semantic segmentation via pixel-text alignment. However, later studies [10, 17, 19, 36, 37, 42] found that although ViTs surpass ResNets in model capacity and classification accuracy, they perform worse on dense alignment tasks."*

**直译：** MaskCLIP [44] 首次展示 CLIP 特征可以通过像素-文本对齐实现零样本语义分割。然而，后续研究 [10, 17, 19, 36, 37, 42] 发现，尽管 ViT 在模型容量与分类精度上超过 ResNet，它们在密集对齐任务上**表现更差**。

**解读：** CLIP 系的脉络：MaskCLIP 打开了"CLIP 做密集预测"的门，随即暴露出 ViT 骨干的密集对齐劣于 ResNet 的矛盾——容量更大、分类更强，密集任务反而更差。既有修补方案被归为三类：
1. **改最后的注意力层**（[10, 17, 19, 36, 38, 42]，如 S-CLIP 重排自注意力的计算方式、ProxyCLIP 用代理注意力）；
2. **加对齐训练**（[3, 37]，如 CLIPSelf 用自蒸馏补对齐、ViT-SR 加自蒸馏 register）；
3. **测试期激活编辑**（[15]，推理时把 high-norm 离群激活动态转移到未训练的 register token 上）。

本文的对照定位原文：

> *"In contrast, our method tackles the problem directly during pretraining, avoiding architectural changes, post-hoc fine-tuning, and test-time interventions, fundamentally preventing the emergence of lazy behavior in text-supervised ViTs."*

**直译：** 相比之下，我们的方法直接在**预训练期间**处理问题，避免架构改动、事后微调与测试期干预，从根本上防止文本监督 ViT 中懒惰行为的出现。

三类既有方案的共同点是**事后修补**（模型已经带着 lazy behavior 训完了，再在推理侧或微调侧打补丁）；LazyStrike 在预训练期改变聚合规则，让 lazy behavior 无从形成。这是"治未病 vs 治已病"的区别。

### 2. 自监督 ViT 的 artifact（DINO 系）与标题的出处

> *"Register [5] found that DINOv2 [25] leads to successful monocular depth estimation and semantic segmentation, but it loses the object detection capability of DINO [1] due to artifacts appearing on the feature map. To address this issue, additional tokens were introduced, designed to store global features and mitigate the impact of these artifacts. During our in-depth analysis of the high-norm phenomenon, we found that high-norm is merely a manifestation of the lazy behavior in later stages. Simply moving the high-norm tokens from the feature map to the register tokens does not fully address the underlying deficiencies in downstream tasks. Therefore, Vision Transformer requires more than just Registers."*

**直译：** Register [5] 发现 DINOv2 [25] 在单目深度估计与语义分割上成功，但由于特征图上出现 artifact，它**丧失了 DINO [1] 的目标检测能力**。为处理该问题，额外的 token 被引入，用于存储全局特征并减轻这些 artifact 的影响。在我们对 high-norm 现象的深入分析中，发现 **high-norm 仅仅是懒惰行为在后期阶段的一种表象**。把 high-norm token 从特征图挪到 register token 上，并不能完全解决下游任务中的潜在缺陷。因此，Vision Transformer 需要的不只是 Registers。

**解读：** 这段是全文标题 "Vision Transformers Need **More Than** Registers" 的直接出处，也是本篇与 Registers 关系的最准确表述：
1. Registers 的发现与方案本身被承认有效——high-norm token 确实被 register token 接走了，特征图确实变干净（Table 1 的 High Norm 列）；
2. 但本文的分析表明 high-norm 只是 lazy aggregation 的**后期表象**：全局语义被扩散进背景 patch 这件事已经发生，register 只是把其中范数最极端的那部分离群值收纳走，背景 patch 承载全局语义的基本格局未变；
3. 所以下游密集任务的缺陷没有被完全修复——Table 1 中 ViT 加 register 后 PiB 从 42.7 降到 41.5 就是量化证据。

另外注意 DINOv2 与 DINO-v1 的能力差异记录：DINOv2 深度估计与分割成功但检测能力丧失，而 DINO-v1 保留检测能力——第 2 站 Table 1 中 DINO-ViT 的 PiB（45.3）与第 4 站 Table 3 中 DINO-v1 的 LazyStrike 增益最大（+25.2）都与这条观察相关。

## 四、第 1 站小结

| 维度 | 内容 |
|---|---|
| 核心问题 | ViT 在标签/文本/自监督三种范式下的 artifact（注意力缺失、密集对齐失败、high-norm token）此前被分别记录、各有修补方案，但无人给出统一机理 |
| 核心结论 | 三种表象源于同一根源：**懒惰聚合**——ViT 把语义无关的背景 patch 当作编码全局语义的捷径 |
| 两个驱动因素 | ① 粗粒度语义监督（图像级标签无空间引导，背景数量占优、共现稳定，是统计上省力的载体）；② 全局注意力（提供前景语义向背景扩散的通道） |
| 统一度量 | Patch Score = patch 特征与 CLS token 的余弦相似度（ConvNet 用 GAP 特征作隐式 CLS），跨范式可比 |
| 量化指标 | Point-in-Box（PiB）= 最高分 patch 落在前景标注框内的图像比例（ImageNet 验证集单目标图） |
| 关键负面证据 | 移除前 50% 高分 patch 不伤 ImageNet 精度（Fig 2）；加 register token 不改善 PiB（Tab 1：42.7 → 41.5） |
| 时间特征 | 背景偏向从训练初期即出现并贯穿全程（Fig 3），不是后期副产品 |
| 解法预告 | LazyStrike：预训练期约束背景 patch 影响、选择性聚合构造 CLS token；零架构改动；同时消除 high-norm 与特征错位；监督范式下也出现分割涌现 |
| 与 Registers 的关系 | Registers 发现并缓解症状（high-norm token）；本篇论证 high-norm 只是 lazy behavior 后期表象，根源在聚合行为本身——"需要的不只是 Registers" |
| 分支位置 | 主线 D 第 2 站：完成"发现症状 → 解释病因并对症修正"的闭环 |
