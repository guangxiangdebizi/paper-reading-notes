## 〇、预备：ViT 的两种全局聚合形式（§3.1）

### 原文 1（架构回顾）

> *"Given an image x ∈ R^(H×W×3), ViTs [7] split it into non-overlapping P × P patches and linearly project them to x_emb ∈ R^(N×D) with N = HW/P² via the patch embedding P_emb(·). An encoder P_enc(·) consisting of a stack of transformer blocks updates tokens with self-attention. Global aggregation is applied to the output of the encoder using one of two standard forms:*
>
> *x_patch = P_enc(P_emb(x)), Q_CLS = Pooling(x_patch), (1)*
> *or*
> *x_patch, Q_CLS = P_enc(P_emb(x), O_CLS), (2)*
>
> *where Pooling is global average pooling (GAP) over patch tokens in Eq. (1); O_CLS is a learnable query concatenated before encoding in Eq. (2), whose output token Q_CLS serves as the global representation."*

**直译：** 给定图像 x ∈ R^(H×W×3)，ViT [7] 将其切分为不重叠的 P × P patch，并通过 patch 嵌入 P_emb(·) 线性投影为 x_emb ∈ R^(N×D)，其中 N = HW/P²。由堆叠的 transformer 块构成的编码器 P_enc(·) 通过自注意力更新 token。全局聚合以两种标准形式之一作用于编码器输出：式 (1) 中 Pooling 是对 patch token 的全局平均池化（GAP）；式 (2) 中 O_CLS 是在编码前拼接的可学习 query，其输出 token Q_CLS 充当全局表示。

**解读：** 这段预备把后文所有公式的记号固定下来，并明确 ViT 获取全局表示 Q_CLS 的两种标准形式：
- **式 (1)：GAP 式**——没有专门 CLS token，编码结束后对所有 patch token 平均池化（ConvNet 的 GAP 层、CLIP 系 ViT 常用）；
- **式 (2)：CLS token 式**——一个可学习的 O_CLS 与 patch token 一起进入编码器，经过全部层与其他 token 交互后，其输出即 Q_CLS（ViT 原论文、DeiT、DINO 采用）。

这两种形式在本文中统一记作 Q_CLS，使 Patch Score 的定义对二者都成立。对 ConvNet，则用 GAP 特征充当隐式 CLS（见下文原文 2）。

## 一、§4.1 新度量：Patch Score 与 Point-in-Box

### 原文 2（Patch Score 定义，Eq.3）

> *"Patch Score. To enable a unified comparison across architectures and pretraining settings, we define the Patch Score as the similarity between each patch and the global representation. For ViTs, the global representation is the CLS token Q_CLS; for ConvNets, it is the feature after global average pooling Q_GAP, which serves as an implicit CLS token. Formally,*
>
> *S_p = (x_patch · Q_CLS) / (‖x_patch‖₂ ‖Q_CLS‖₂), (3)*
>
> *where higher Patch Scores indicate stronger alignment with image-level semantics."*

**直译：** **Patch Score。** 为实现跨架构与跨预训练设置的统一比较，我们把 Patch Score 定义为每个 patch 与全局表示之间的相似度。对 ViT，全局表示是 CLS token Q_CLS；对 ConvNet，是全局平均池化后的特征 Q_GAP，它充当隐式 CLS token。形式化地，S_p = (x_patch · Q_CLS) / (‖x_patch‖₂ ‖Q_CLS‖₂)，其中更高的 Patch Score 表示与图像级语义更强的对齐。

**解读：** Eq.3 就是 patch 特征与全局特征之间的**余弦相似度**。三点说明：
1. **取值范围 [-1, 1]**，只比较方向、不比较范数——这个选择很关键：它使度量对 high-norm token 的范数离群性不敏感（一个 patch 范数很大但方向与 CLS 垂直，Patch Score 依然低），从而把"方向上的语义对齐"与"范数上的离群"两个问题拆开。后文将证明前者才是根因；
2. **ConvNet 的适配**：ResNet 没有 CLS token，但其 GAP 特征（最后一个卷积特征图的空间平均）在功能上就是全局表示，用它当 Q_CLS 即可同尺比较。这是 Table 1 能把 ViT 与 ResNet 放在同一张表里的原因；
3. **语义解读**：由于训练目标把 Q_CLS 对齐到监督信号，S_p 高的 patch 即"自认为承载了这张图类别语义"的 patch。正常预期：前景目标区域的 patch 得高分；异常（artifact）：背景 patch 得高分。

### 原文 3（Point-in-Box 基准）

> *"Point-in-Box benchmark. Building on the patch score, we assess artifacts by determining whether the highest scoring regions correspond to foreground objects. We use images from the ImageNet [6] validation set that feature a single object annotation to avoid ambiguity. We define the Point-in-Box score as the proportion of images where the highest patch score falls within the foreground bounding box."*

**直译：** **Point-in-Box 基准。** 在 patch score 基础上，我们通过判定最高分区域是否对应前景目标来评估 artifact。为避免歧义，使用 ImageNet [6] 验证集中带单一目标标注的图像。Point-in-Box 分数定义为最高 patch score 落在前景标注框内的图像比例。

**解读：** PiB 把一个 196 维的分布问题压缩成一个二值判断再取平均，得到可追踪的标量：
- **判据极简**：只看**最高分的那一个 patch**是否在前景框内。这个极简判据的好处是零阈值、零超参，坏处是只考察了分布的极端点（后文 Fig 2a 的完整分布分析是对它的补充）；
- **单目标约束**：ImageNet 验证集多数图只有一个主要目标，筛选出单目标图后，"最高分 patch 应该在哪儿"没有歧义；
- **方向性**：PiB 越高，模型的"注意力落点"越贴近前景；PiB 低说明全局语义的承载者错位到了背景。

### 原文 4（Table 1 核心发现）

> *Table 1. Point-in-Box (PiB) across different supervision methods. We find that Register reduces high-norm tokens but high-norm is not the root cause of artifacts.*

表 1 数据（PiB，%）：

| 方法 | High Norm | Point-in-Box (PiB) |
|---|---|---|
| ResNet [11] | （无此现象） | 68.4 |
| ViT [7] | （有） | 42.7 |
| ViT + Register [5] | （消除） | 41.5 |
| DINO-ResNet [1] | （无此现象） | 71.1 |
| DINO-ViT [1] | （有） | 45.3 |
| OpenCLIP-ResNet [27] | （无此现象） | 53.9 |
| OpenCLIP-ViT [27] | （有） | 39.8 |
| OpenCLIP-ViT + Register [5] | （消除） | 37.6 |

**解读：** Table 1 是全文的"总诊断书"，读出三条结论：
1. **ViT 全面低于对应 ResNet**：标签监督 42.7 vs 68.4（差 25.7）；DINO 自监督 45.3 vs 71.1（差 25.8）；OpenCLIP 文本监督 39.8 vs 53.9（差 14.1）。三种范式下差距的方向完全一致——最高分 patch 落在前景的概率，ViT 远低于 ConvNet；
2. **三种范式的绝对水平**：文本监督的 OpenCLIP-ViT 最差（39.8），标签监督次之（42.7），DINO 自监督相对最好（45.3）——DINO 的目标发现能力是出了名的，但其 PiB 也远不及 DINO-ResNet（45.3 vs 71.1），说明即便以分割/定位见长的 DINO，换到 ViT 骨干后同样染上背景偏向；
3. **Register 不改善 PiB**：ViT 42.7 → 41.5，OpenCLIP-ViT 39.8 → 37.6，加入 register token 后 PiB 不升反降。由于 register 确实消除了 high-norm token（表中 High Norm 列），这构成关键的反证：**high-norm token 不是 artifact 的根因**——把症状消掉，病还在。题注原文即此意："Register reduces high-norm tokens but high-norm is not the root cause of artifacts."

## 二、§4.2 Patch Score 中的 artifact：空间与时间

§4.2 按"空间分布 → 掩码探针 → 训练动态"三步展开，对应 Fig 2a、Fig 2b、Fig 3。实验对象为 ImageNet-1k 全监督训练的 ViT-B/16。

### 原文 5（空间分布：前景在低分区，背景占据高分尾部）

> *"Distribution. Foreground patches concentrate at lower patch-score values, while background patches dominate the high-score tail (Fig. 2a)."*

**直译：** **分布。** 前景 patch 集中在较低的 patch-score 取值区间，而背景 patch 主导高分尾部（图 2a）。

**解读：** Fig 2a 把 ImageNet 验证集所有 patch 按标注分为前景/背景两类，分别画归一化 Patch Score 密度曲线：
- 前景 patch 的密度峰位于低分区域；
- 背景 patch 的密度虽然主体也在低分区，但**高分尾部几乎全部由背景贡献**；
- 合起来的直观含义：模型判定"最承载这张图语义"的那批 patch，大多数不是目标本身而是背景。这与 Table 1 的 PiB 低值互为表里（PiB 只看分布的极端点，Fig 2a 给出整个分布形态）。

### 原文 6（掩码探针：高分 patch 对分类不提供独占信息）

> *"Masking Probe. Removing high-score patches does not harm accuracy--and can even slightly improve it (e.g., +1.2% for ViT-B/16)--even when more than 50% of patches are masked. In contrast, removing low-score patches leads to a sharp accuracy drop (up to 60% at 70% masking; Fig. 2b)."*

**直译：** **掩码探针。** 移除高分 patch 不损害精度——甚至可以略微提升（例如 ViT-B/16 提升 1.2%）——即使遮住超过 50% 的 patch。相反，移除低分 patch 导致精度骤降（70% 掩码时最多跌 60%；图 2b）。

**解读：** Fig 2b 的探针设计：直接在输入图像上遮住 top-k 或 bottom-k 个 patch（按 Patch Score 排序，从训练好的模型前向推理，不重训），三种移除顺序对照——High Patch Score First / Random Order / Low Patch Score First：
- **high-first（先遮高分）**：遮到约 70% 精度基本不掉，ViT-B/16 甚至 +1.2%；
- **low-first（先遮低分）**：剩余 28/56/196 个可见 patch 时精度约 81.1%/70.3%/22.3%，即遮掉 70% 低分 patch 后精度跌约 60%；
- **random（随机）**：介于两者之间。

这组对照的推理结构是：如果高分 patch 真的承载了独占的类别语义，high-first 应该最先摧毁精度；实测恰好相反。因此**高分 patch 承载的信息是冗余的、可替代的**——与"前景语义已被扩散到大量背景 patch、每个背景 patch 只持有其中一份副本"的 lazy aggregation 图景吻合（遮掉一部分副本，剩余副本仍足够 CLS 读出全局语义；而低分的真前景 patch 一旦被遮，扩散出去的副本反而不足以支撑识别）。原文 §4.2 的解读句：

> *"Masking out background patches in the input image barely affects classification performance, yet these regions show feature responses strongly correlated with the CLS token that encodes class semantics, suggesting that foreground information has been propagated into the background during training--a behavior likely driven by the dominance of background tokens over foreground ones in natural images (as shown in Fig. 2b, where over half of the patches are non-contributive to classification)."*

**直译：** 遮住输入图像中的背景 patch 几乎不影响分类性能，然而这些区域表现出与编码类别语义的 CLS token 强相关的特征响应，表明前景信息在训练过程中已被传播到背景中——这一行为很可能是由自然图像中背景 token 相对前景 token 的数量优势所驱动的（如图 2b 所示，其中超过一半的 patch 对分类没有贡献）。

### 原文 7（时间动态：背景偏向从训练初期即出现且持续）

> *"Point-in-Box dynamics. The Point-in-Box score of ViT, reflecting artifact level (lower indicates stronger background bias), stays low and nearly unchanged during training, even as classification accuracy improves (Fig. 3). Comparison with ResNet. Compared with ResNet, ViT consistently shows a lower Point-in-Box score, revealing a more pronounced background bias despite similar image-level accuracy (Fig. 3). Even at early iterations, the CLS token already attends predominantly to background patches instead of foreground regions, and this bias persists throughout training--yielding accurate image-level predictions but poor patch-level alignment."*

**直译：** **Point-in-Box 动态。** ViT 的 Point-in-Box 分数反映 artifact 程度（越低表示背景偏差越强），在训练过程中保持低位且几乎不变，即便分类精度持续提升（图 3）。**与 ResNet 对比。** 与 ResNet 相比，ViT 始终表现出更低的 Point-in-Box 分数，揭示出尽管图像级精度相近，其背景偏差更为显著（图 3）。**即使在训练早期迭代，CLS token 已经主要注意背景 patch 而非前景区域，且该偏差贯穿整个训练过程**——产生准确的图像级预测，但 patch 级对齐很差。

**解读：** Fig 3 的实验设置：用**完全相同的超参与 batch size** 从头训练 ViT-B/16 与 ResNet-50，全程同时跟踪 top-1 精度与 PiB。读出的三个事实：
1. **ViT 的 PiB 全程平坦**：约 0.42–0.44，从训练初期到收敛几乎不动；
2. **同期精度正常上升**：分类精度该涨照涨，最终两者图像级精度相当——即"精度提升"与"对齐改善"完全解耦，分类任务本身不奖励 patch 级对齐；
3. **早期即出现**：训练最初若干迭代，CLS token 的注意已经主要落在背景 patch 上。

第三点排除了一个备择假设：artifact 不是"训练后期过拟合/容量过剩"的副产品，而是**训练一开始就被优化过程选中的策略**。原文给出的机理解释：

> *"We hypothesize that at the start of training, the CLS token seeks the easiest path to minimize the image-level loss, quickly learning to aggregate background tokens that correlate with the image-level label. As a result, image-level semantics are 'short-circuited' through background regions, leading to high classification accuracy but poor patch-level alignment--a hallmark of the model's lazy aggregation behavior."*

**直译：** 我们假设在训练开始时，CLS token 寻求最小化图像级损失的**最容易路径**，迅速学会聚合与图像级标签相关的背景 token。于是图像级语义经由背景区域被"短路"，导致高分类精度但 patch 级对齐很差——这是模型懒惰聚合行为的标志。

随后原文把该行为归因于两个相互作用的因素，并预告隔离实验：

> *"We next hypothesize that this behavior originates from two interacting factors: (1) Coarse-grained semantic supervision, where image-level labels cannot provide accurate patch-level supervision; and (2) Global dependencies, where attention-based token mixing allows background tokens to absorb foreground information. Sections 4.3 and 4.4 further isolate and quantify the contribution of each factor."*

**直译：** 我们进一步假设该行为源于两个相互作用的因素：（1）**粗粒度语义监督**——图像级标签无法提供准确的 patch 级监督；（2）**全局依赖**——基于注意力的 token 混合使背景 token 得以吸收前景信息。§4.3 与 §4.4 进一步隔离并量化各因素的贡献。

## 三、§4.3 因素一验证：粗粒度语义监督

### 原文 8（验证设计：加大 patch size 稀释背景 token）

> *"To evaluate the effect of coarse-grained semantic supervision, we reduce the prevalence of background tokens by increasing the patch size used in the embedding module P_emb(·). As the patch size grows, fewer tokens are generated, and many small background regions are merged into larger patches, thereby reducing the relative proportion of background tokens. Specifically, we train ViT-Base on ImageNet-1k [6] with a 28×28 patch size (default: 16×16), which decreases the proportion of background tokens by about 10% (see Appendix for details)."*

**直译：** 为评估粗粒度语义监督的效应，我们通过增大嵌入模块 P_emb(·) 所用 patch 尺寸来降低背景 token 的占比。patch 尺寸增大后，生成的 token 变少，许多小背景区域被并入更大的 patch，从而降低背景 token 的相对比例。具体地，在 ImageNet-1k [6] 上以 28×28 patch 尺寸（默认 16×16）训练 ViT-Base，使背景 token 比例下降约 10%（细节见附录）。

**解读：** 这个验证实验的设计逻辑是**干预-响应**结构：
- **假设预测**：如果 lazy aggregation 依赖"背景 token 数量占优"这一统计条件，那么人为减少背景 token 的相对占比，应能削弱背景捷径、改善 PiB；
- **干预手段**：patch size 16×16（196 个 token）→ 28×28（约 64 个 token）。小块背景（目标边缘、缝隙里的背景）被并入大 patch，背景 token 相对比例下降约 10%；
- **为什么不用 patch 级标注做干预**：那样会直接改变监督粒度、无法区分"是监督变细了"还是"背景占比变了"；加大 patch 是在保持图像级监督不变的前提下只改 token 统计结构，隔离更干净。

### 原文 9（验证结果：PiB 升、精度降的权衡）

> *"As shown in Fig. 4, Point-in-Box increases from 0.44 to 0.52 after enlarging the patch size, which reduces the proportion of background tokens by about 10%. Patch-score maps show that high-score regions shift from background to object areas. However, top-1 accuracy drops from 62% to 55%, revealing a trade-off between classification and localization accuracies."*

**直译：** 如图 4 所示，增大 patch 尺寸（背景 token 比例下降约 10%）后，Point-in-Box 从 0.44 升至 0.52。Patch-score 图显示高分区域从背景转向目标区域。然而，top-1 精度从 62% 跌至 55%，揭示出**分类精度与定位精度之间的权衡**。

**解读：** 三个观测值与图注（Fig 4 题注）对应：
- **干预效应**：PiB 0.44 → 0.52（+0.08），高分区域从背景移向目标——背景占比下降确实削弱了背景捷径，支持因素一；
- **代价**：top-1 从 62% 跌到 55%（−7）。注意这是 ViT-Base 在该训练设置下的对照数值，重点不在绝对水平而在差值方向；
- **权衡的解读**（原文题注）："coarse-grained semantic supervision contributes to artifacts, while naive patch coarsening compromises recognition"——粗粒度监督确实助推了 artifact（干预有效），但简单地把 patch 变粗会牺牲识别性能（token 总数骤减、分辨率变粗，表示能力受损），因此**不能靠加大 patch 来修复 artifact**。这个负面结果恰好为第 3 站的 LazyStrike 铺路：需要在不损失 token 数量与分辨率的前提下约束背景的影响。

## 四、§4.4 因素二验证：ViT 的全局依赖

### 原文 10（验证设计：逐层替换窗口注意力）

> *"We further examine whether ViT's global attention exacerbates the lazy aggregation behavior by allowing foreground semantics to be propagated into background regions. To progressively restrict long-range dependencies, we replace global self-attention with window-based attention [21] at different layers."*

**直译：** 我们进一步考察 ViT 的全局注意力是否通过允许前景语义传播进背景区域而加剧懒惰聚合行为。为渐进地限制长程依赖，在不同层把全局自注意力替换为基于窗口的注意力 [21]。

**解读：** 验证设计与 §4.3 同构：
- **假设预测**：如果全局注意力是前景语义向背景扩散的通道，限制该通道应能缓解 artifact；
- **干预手段**：窗口注意力（引用 [21] 即 Swin 的窗口机制）——每个 token 只与同窗口内的 token 交互，跨窗口信息流被切断；
- **梯度设计**：不是全有全无，而是三档对照——完全不换（None）、换部分层（第 1、5、9、11 层）、全部换（All），观察剂量-响应关系。实验对象为 ViT-Small，窗口大小 4。

### 原文 11（Table 2 结果：剂量-响应关系成立）

表 2 数据（ViT-Small 窗口注意力消融）：

| Replaced Layer | Window Size | Top-1 (IN1K) | Point-in-Box |
|---|---|---|---|
| None | None | 72.3 | 50.1 |
| 1, 5, 9, 11 | 4 | 71.7 | 52.1 |
| All | 4 | 63.9 | 59.8 |

> *"The Point-in-Box score increases as global attention is limited, with the highest value achieved when all layers adopt window attention. However, accuracy declines correspondingly, implying that while global context benefits classification, it also facilitates semantic diffusion into background patches."*

**直译：** 随着全局注意力被限制，Point-in-Box 分数上升，且在所有层都采用窗口注意力时达到最高值。然而精度相应下降，这意味着全局上下文虽然有利于分类，但也**助推了语义向背景 patch 的扩散**。

**解读：** Table 2 呈现清晰的剂量-响应关系：
- **PiB 单调上升**：50.1（全局）→ 52.1（部分窗口）→ 59.8（全窗口），窗口化程度越高、背景偏差越弱——全局注意力确实是前景语义扩散进背景的通道，因素二成立；
- **Top-1 单调下降**：72.3 → 71.7 → 63.9，且全窗口时跌幅最大（−8.4）——全局上下文对分类确有真实贡献（这解释了为什么 ViT 进化出了这种依赖：它在图像级任务上是有收益的），但这份收益与背景捷径绑定在一起；
- 原文题注的总结："Restricting global dependencies raises Point-in-Box but reduces top-1 accuracy. This suggests that unrestricted global attention amplifies lazy behavior, as coarse-grained semantic supervision allows background tokens to absorb diffused semantics from the foreground."——不受限的全局注意力放大了懒惰行为，而粗粒度监督允许背景 token 吸收从前景扩散来的语义。两个因素的交互关系在这句话里合拢。

与 §4.3 同样的结论：窗口注意力也不是可行的修复方案——全窗口时精度损失太大（ViT 相对 ConvNet 的核心优势恰恰来自全局建模）。两个隔离实验共同确立了病因，同时排除了两种"粗暴疗法"，方法必须另寻出路。

## 五、§4 小结（Takeaway）

### 原文 12（本段总结）

> *"Takeaway: When vision transformers are trained under coarse-grained semantic supervision and equipped with unrestricted global dependencies, they tend to pursue the easiest optimization path--diffusing foreground semantics into abundant background tokens. This shortcut yields high image-level accuracy but results in representations dominated by background information, showing that optimizing for global classification objectives can compromise patch-level semantic consistency in ViTs."*

**直译：** **要点：** 当视觉 transformer 在粗粒度语义监督下训练、并具备不受限的全局依赖时，它们倾向于追求**最容易的优化路径**——把前景语义扩散进大量的背景 token。这条捷径带来高图像级精度，但产生由背景信息主导的表示，表明对全局分类目标的优化可能损害 ViT 中 patch 级的语义一致性。

**解读：** 这段 takeaway 把 §4 的完整因果链定型：**监督粒度粗（无 patch 级约束）+ 信息通道全局（注意力无界）→ 优化选择最省力路径（前景语义扩散进数量占优的背景）→ 图像级精度与 patch 级对齐解耦（前者高、后者差）**。值得注意最后一句的普适性表述："optimizing for global classification objectives can compromise patch-level semantic consistency"——这不是某个模型或配方的缺陷，而是"全局分类目标"这一优化形式与"patch 级一致性"之间的结构性张力，因此三种监督范式（其目标都是全局的：类别、图文对、全局自蒸馏）无一幸免。
