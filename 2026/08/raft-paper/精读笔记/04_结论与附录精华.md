## 一、§5 结论：三句话的墓志铭

**原文：**
> *"We have proposed RAFT ... RAFT is unique in that it operates at a single resolution using a large number of lightweight, recurrent update operators. Our method achieves state-of-the-art accuracy across a diverse range of datasets, strong cross dataset generalization, and is efficient in terms of inference time, parameter count, and training iterations."*

浓缩成三个词：**单一分辨率、轻量循环、全面占优**。结论短到几乎没有废话——因为该说的消融都说了。

## 二、附录 A：完整架构图里的隐藏细节（Figure 7）

正文只给了概念图，附录给了**逐层的工程图纸**，里面有几个值得注意的不对称设计：

### 1. 特征编码器 vs 上下文编码器：归一化方式不同

> *"the context and feature encoders have the same architecture, the only difference is that the feature encoder uses **instance normalization** while the context encoder uses **batch normalization**."*

**解读：** 两个编码器结构完全一样（7×7 卷积 + 6 个残差块，逐级 ½→¼→⅛），但：
- **特征编码器用 InstanceNorm**——因为它处理的是"两帧各自的像素特征"，要做跨帧匹配，必须**去掉图像间的全局亮度/对比度差异**（不然两帧光照不同就匹配不上了），InstanceNorm 逐样本归一化，正好抹掉这些；
- **上下文编码器用 BatchNorm**——它只处理 I1，保留全局统计量没问题，还能帮助稳定训练。

这种"同一个结构、不同的归一化"是典型的**任务感知微调**——值得偷师。

### 2. 完整模型用"可分离 ConvGRU"：两个串联的小 GRU

> *"The full model uses two convolutional GRU update blocks with 1x5 filters and 5x1 filters respectively, while the small model uses a single GRU with 3x3 filters."*

**解读：** separable ConvGRU 的落地方式：先用 1×5（横向长条）GRU，再用 5×1（纵向长条）GRU——两个方向分解的卷积**扩大感受野又不堆参数**。更新块隐藏层维度：完整模型 128，小模型 96。

### 3. 参数账本

RAFT 完整模型 4.8M（加上采样模块 5.3M），RAFT-S 1.0M（残差块换成瓶颈结构）。

## 三、附录 C：训练配方——光流版的"增强三板斧"

训练阶梯（Table 3）：

```
Chairs（lr 4e-4）→ Things（1.2e-4）→ Sintel 混训（1.2e-4）→ KITTI（1e-4）
```

Sintel 微调阶段的数据配比很有意思：**Sintel 71% + FlyingThings 13.5% + KITTI 13.5% + HD1K 2%**——微调时仍掺大量合成数据，防止在小数据集上灾难性遗忘。

**三种数据增强，每种都针对光流的痛点：**

| 增强 | 做法 | 针对的痛点 |
|---|---|---|
| **光度增强** | ColorJitter 扰动亮度/对比度/饱和度/色相；20% 概率**对两帧独立扰动** | 逼特征对光照变化鲁棒——两帧光照不同时照样匹配 |
| **空间增强** | 随机缩放拉伸（概率 0.8） | 尺度多样性 |
| **遮挡增强** ⭐ | **以 0.5 概率随机擦掉 I2 中的矩形区域**（学自 HSM-Net） | **模拟遮挡**——被擦的区域在 I1 有、I2 没有，正是遮挡的定义 |

**🔑 遮挡增强的妙处：** 它**只擦 I2，不擦 I1**——人为制造出"像素在 I1 存在、在 I2 找不到对应"的情况，逼网络学会"这里不该硬匹配"。这是"用数据模拟四大天敌之一"的标准操作，和 DeiT 用 CutMix 逼模型学局部重建是同一个思想：**增强不只是正则化，是在给模型出它必须学会的考题。**

## 四、附录 D：收敛性的数学证据（Figure 10）

**左图**：EPE 随推理迭代次数的下降曲线——前 8 次陡降，之后平缓收敛。

**右图（最有数学味）：** 每步更新量的模 ‖Δf_k‖（全像素平均）随迭代 k **指数衰减**——这是"收敛到不动点 f_k → f*"的直接证据，不是口头声明，是实测曲线。循环架构"可以无限迭代"在这里有了定量背书。

**还有一个工程彩蛋：**
> *"We can also train RAFT using mixed precision training and achieve similar results while training on only a single GPU."*

混合精度训练下，**单张 GPU 就能训 RAFT**。2020 年的 SOTA 光流，训练门槛低到一张卡——这为它成为"社区默认光流"铺平了路。

## 🏁 RAFT 全书收官

**一张图总览：**

```
主张：光流可以做成"可微的迭代优化"——特征、先验、下降方向全部学出来
  │
  ├─ 架构：特征/上下文双编码器 → 4D 全配对相关体（金字塔只池化查询侧）
  │         → 2.7M ConvGRU 循环查表，权重共享，f0=0 起步
  │
  ├─ 三大创新：单一分辨率流场（废 coarse-to-fine）/ 轻量循环器 / 相关体查表
  │
  ├─ 证据：KITTI F1-all 5.10%（−16%）、Sintel EPE 2.855（−30%）、
  │         纯合成训练上真实场景错误降 40%、200 次迭代不发散
  │
  └─ 遗产：光流事实标准；后续 FlowFormer/CoTracker/视频理解的运动基座
```

**读完后你应该能回答的四个大问题：**

1. **RAFT 是什么？** —— 把经典光流优化框架（数据项+正则项+迭代下降）整体翻译成端到端网络：特征编码器=数据项、上下文网络=正则项、共享权重的 ConvGRU=下降步。
2. **它为什么掀翻了 coarse-to-fine 时代？** —— 相关金字塔一个结构解掉两大死穴：I1 侧不池化保住小快物体，I2 侧池化覆盖大位移。
3. **它为什么泛化这么强？** —— 循环结构本身是正则化，逼网络学通用下降步；加上针对四大天敌的增强配方（尤其遮挡擦除）。
4. **它改变了什么？** —— 光流从"各种专用架构混战"变成"RAFT + 在它上面改"；1M 参数的版本让实时视频应用（抽帧冗余判定、运动分析）第一次用得起高质量光流。
