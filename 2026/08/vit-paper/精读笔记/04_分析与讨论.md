## 一、§4.5 Inspecting Vision Transformer：解剖 ViT

这一节是全文最有"科学味"的部分——前面都是在比分数，这里开始**理解机制**。作者解剖了三个部位。

### 解剖部位 1：第一层的"嵌入滤波器"（Figure 7 左）

**原文：**
> *"Figure 7 (left) shows the top principal components of the learned embedding filters. The components resemble plausible basis functions for a low-dimensional representation of the fine structure within each patch."*

**解读：** 还记得吗，ViT 的第一层是把 16×16 patch 线性投影到 D 维的那个矩阵 E。作者把这个投影矩阵**反过来看**——它等价于一组 16×16 的"滤波器"。对这些滤波器做 PCA，发现它们**长得像合理的图像基函数**（类似边缘、纹理之类的低频/高频模式）。

**深意：** CNN 的第一层卷积核学到的就是 Gabor 状的边缘滤波器。ViT 的第一层在**没有任何监督信号告诉它"图像长什么样"**的情况下，自己学出了类似的东西。这是"白纸从数据中学出视觉先验"的第一个直接证据。

### 解剖部位 2：位置编码自己学出的 2D 结构（Figure 7 中）⭐

**原文：**
> *"the model learns to encode distance within the image in the similarity of position embeddings, i.e. closer patches tend to have more similar position embeddings. Further, the row-column structure appears; patches in the same row/column have similar embeddings."*

**解读：** 这是全文最漂亮的发现之一。回忆一下：作者喂给模型的是**一维**位置编码，**没有**任何 2D 信息。但把学出来的位置编码两两算余弦相似度、画成热力图，发现：

1. **距离编码**：图像里离得近的 patch，位置编码越相似——模型自己学出了"空间邻近"概念。
2. **行列结构**：同一行、同一列的 patch 位置编码相似——一维编码里**自发涌现**出了二维的行列结构。
3. 网格大时甚至能看到类似**正弦**的周期性结构（和原 Transformer 手工设计的正弦编码神似！）。

**🔑 深意：** 这直接解释了 §3.1 里那个反直觉的结论——"为什么手工的 2D 位置编码没有带来增益"。答案是：**模型自己就能从 1D 编码中学出 2D 拓扑，不需要你喂。** 先天给的和后天学的，殊途同归。这又是 "large scale training trumps inductive bias" 在微观层面的一次验证。

### 解剖部位 3：注意力距离 —— ViT 版的"感受野"（Figure 7 右）

**原文：**
> *"We compute the average distance in image space across which information is integrated, based on the attention weights. This 'attention distance' is analogous to receptive field size in CNNs."*

**解读：** 作者发明了一个指标——**注意力距离**：以注意力权重为权，计算每个 query 像素和它"看的"所有像素之间的平均距离。这就是 CNN "感受野"概念在 Transformer 里的对应物。

**三个观察结果：**

1. **有些头从最底层就环顾全图**（attention distance 很大）——全局整合能力不是摆设，是真在用。
2. **另一些头在底层只看很小的邻域**（高度局部化）——这些头扮演的正是 CNN 浅层卷积的角色！
3. 注意力距离**随网络深度增加**；在 hybrid 模型（前面接了 ResNet）里，这种底层小注意力的现象**变弱了**——因为 ResNet 已经把局部特征提取干完了。

**深意：** 第 2 条尤其精妙。它表明 ViT 的注意力头**自发分工**：一部分头学会了"卷积"的活（局部），一部分头干卷积干不了的事（全局）。这从机制上解释了 §4.4 的发现 2（为什么大 ViT 不需要 hybrid 外挂 CNN）。

**Figure 6** 还展示了定性结果：注意力确实落在**语义相关**的区域（看鸟的图，注意力在鸟身上）。

## 二、§4.6 自监督：未来埋下的种子

**原文：**
> *"we also perform a preliminary exploration on masked patch prediction for self-supervision, mimicking the masked language modeling task used in BERT."*

**解读：** 仿照 BERT 的"完形填空"：把 50% 的 patch 遮掉（80% 换成 [mask]、10% 换成随机 patch、10% 原样保留——和 BERT 配方一模一样），让模型预测被遮 patch 的**3-bit 平均颜色**（512 色分类问题）。

**结果：** ViT-B/16 自监督预训练后在 ImageNet 达到 **79.9%**——比从头监督训练高 2 个点，但比大规模监督预训练低 4 个点。

**为什么这一小节重要？** 它本身是个"初步探索"（preliminary），成绩也谈不上惊艳。但它的历史意义巨大——**这就是 MAE（Masked Autoencoders, 2021）的直接思想源头**。作者自己也在结尾点名：对比学习留待 future work。后来的历史证明，这条路线（遮块重建 + 对比学习）成了视觉自监督的主干道。读论文读到这里，你会看到一篇论文如何**给整个领域划出未来的跑道**。

## 三、结论 §5：三句话总结全文 + 三件未竟之事

**结论段第一句就是全文的墓志铭：**

> *"we do not introduce image-specific inductive biases into the architecture apart from the initial patch extraction step. Instead, we interpret an image as a sequence of patches and process it by a standard Transformer encoder as used in NLP. This simple, yet scalable, strategy works surprisingly well when coupled with pre-training on large datasets."*

**三个未来方向**（每一个后来都成真了）：

| 论文提出的方向 | 后来的兑现 |
|---|---|
| 把 ViT 用到检测、分割 | DETR 已有苗头，后来 Swin / Mask R-CNN 全面开花 |
| 继续探索自监督预训练 | MAE / BEiT |
| 继续 scale | 这条路的尽头是今天的多模态大模型 |

## 四、附录里的隐藏干货（精选四则）

### 📎 附录 D.3：[class] token vs 全局平均池化 —— 一个"学习率陷阱"

**原文：**
> *"An initial attempt at using only image-patch embeddings, globally average-pooling them ... performed very poorly. However, we found that this is neither due to the extra token, nor to the GAP operation. Instead, the difference in performance is fully explained by the requirement for a different learning-rate."*

**解读：** 作者一开始发现"去掉 [class] token、改用池化"效果很差，差点以为 [class] 是必需的。深挖后发现：**两种方案效果一样好，只是各自需要不同的学习率**（Figure 9 给出证据）。这是深度学习实验里经典的"超参混淆变量"陷阱。教训：**下结论前，先排除学习率这个捣蛋鬼。**

### 📎 附录 D.4：位置编码消融（Table 8）

| 位置编码方式 | ImageNet 5-shot 线性精度 |
|---|---|
| 不加位置编码（把 patch 当词袋） | 61.4% ⬇️ 大幅掉点 |
| 1D 位置编码（论文默认） | **64.2%** |
| 2D 位置编码 | 64.0% |
| 相对位置编码 | 64.0% |

**结论：** 位置信息**必不可少**（不加掉 3 个点），但**怎么加几乎无所谓**。作者的解释：patch 级输入的空间网格很小（14×14 而不是 224×224），对任何编码方案来说学空间关系都很容易。——这再次呼应正文：**1D 够用，2D 结构模型会自己学。**

### 📎 附录 D.2：Transformer 应该往哪个方向做大？

作者分别缩放深度、宽度、MLP 宽度、patch 大小（Figure 8）：

- **深度**收益最大（但 16 层后边际递减）
- **宽度**收益最小
- **缩小 patch**（=加长序列，**不增加参数**！）带来惊人稳健的提升
- 最终感悟：*"compute might be a better predictor of performance than the number of parameters"*——**算力比参数量更能预测性能**，要 scale 就优先加深度。

这句话在 2020 年极具前瞻性——后来 Chinchilla 的 scaling law 研究说的正是同一件事。

### 📎 附录 B.1.2 彩蛋：自监督比想象中便宜

作者补了一句：他们的 masked patch prediction **不需要** JFT 那么大的数据，也不需要 1M 步训练——100k 步后收益就饱和了，在 ImageNet 上预训练也能看到类似增益。（后来 MAE 把这一路线彻底做大了。）

## 🏁 全文收官：一张图总览

```
主张：纯 Transformer 可以做好视觉（不需要 CNN）
  │
  ├─ 方法：图像分词 → patch embedding → [+CLS, +位置编码] → L 层标准 Encoder
  │         （唯一人工 2D 先验：切 patch + 位置编码插值）
  │
  ├─ 代价：没有归纳偏置 → 小数据下过拟合、打不过 CNN
  │
  ├─ 解药：大规模预训练（JFT-300M）→ "large scale training trumps inductive bias"
  │
  ├─ 证据：打赢 BiT-L（同数据）；打赢 Noisy Student（算力省 4-5 倍）；
  │         2-4× 算力性价比；曲线不饱和；注意力头自发分工
  │
  └─ 遗产：开启视觉 Transformer 时代 → DETR/Swin/MAE/多模态大模型
```

### 读完后你应该能回答的四个大问题

1. **ViT 是什么？** —— 把图像切成 16×16 的 patch 当作 token，喂给标准 NLP Transformer。
2. **它为什么一开始不被看好？** —— 缺归纳偏置，中等数据上打不过 ResNet。
3. **它凭什么翻盘？** —— 大数据。300M 规模下归纳偏置从资产变负担，白纸模型上限更高、算力效率更好。
4. **它改变了什么？** —— 证明了视觉不需要 CNN 专利，统一了视觉与语言的架构范式，直接铺就了今天多模态大模型的路。
