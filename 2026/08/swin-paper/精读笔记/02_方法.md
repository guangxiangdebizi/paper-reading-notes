## 一、相关工作：四条赛道，各自点名（§2）

Swin 的相关工作写得像一份行业地图，把 2021 年初视觉注意力的所有玩家分成四派逐一点评。这个写法值得学：**先给对手分门别类，再在每一类里说清楚"它卡在哪、我从哪超"**。

### 派系一：CNN 及其变体（当朝正统）

> *"While the CNN and its variants are still the primary backbone architectures for computer vision applications, we highlight the strong potential of Transformer-like architectures for unified modeling between vision and language."*

**直译：** 尽管 CNN 及其变体仍是计算机视觉应用的主要骨干架构，我们强调类 Transformer 架构在视觉与语言统一建模上的巨大潜力。

**解读：** 对 CNN 一派（AlexNet → VGG/GoogLeNet/ResNet/DenseNet/HRNet/EfficientNet，外加 depthwise/deformable convolution 等卷积改良）的态度是**尊重但不恋战**：承认统治地位，但话锋一转，把卖点从"比 CNN 准"升级到"视觉-语言统一建模"——这是 CNN 结构上给不了的东西。

### 派系二：用自注意力替换卷积的骨干网（最直接的对手）

> *"In these works, the self-attention is computed within a local window of each pixel to expedite optimization, and they achieve slightly better accuracy/FLOPs trade-offs than the counterpart ResNet architecture. However, their costly memory access causes their actual latency to be significantly larger than that of the convolutional networks. Instead of using sliding windows, we propose to shift windows between consecutive layers, which allows for a more efficient implementation in general hardware."*

**直译：** 在这些工作中，自注意力在每个像素的局部窗口内计算以加速优化，并取得了比对应 ResNet 架构略好的精度/FLOPs 权衡。然而其昂贵的内存访问使其实际延迟显著高于卷积网络。我们不用滑动窗口，而是提出在连续层之间移动窗口，这使得在通用硬件上能有更高效的实现。

**解读：** 这一派（滑动窗口自注意力替换 ResNet 的卷积层）就是引言里被点名的"延迟差"方案。FLOPs 账面上好看、真机跑得慢——问题出在访存。**Swin 对这一派的超越点是工程性的，不是理论性的**：同样的局部注意力思想，换一种窗口组织方式，延迟就下来了。这也解释了为什么论文要反复晒延迟数据而不只是 FLOPs。

### 派系三：自注意力给 CNN 打下手（互补派）

> *"The self-attention layers can complement backbones or head networks by providing the capability to encode distant dependencies or heterogeneous interactions. More recently, the encoder-decoder design in Transformer has been applied for the object detection and instance segmentation tasks. Our work explores the adaptation of Transformers for basic visual feature extraction and is complementary to these works."*

**直译：** 自注意力层可以为骨干网或头网络提供编码长程依赖或异质交互的能力，从而起到互补作用。最近，Transformer 的编码器-解码器设计已被应用于目标检测与实例分割任务。本文探索的是将 Transformer 用于基础视觉特征提取，与这些工作互补。

**解读：** 这一派里既有把注意力塞进 CNN 的改良派（各类 SE/SA 模块），也有 DETR 这类"Transformer 做检测头"的先驱。Swin 划清界限：**别人把 Transformer 当配菜或当餐具，本文要做的是主菜（骨干网）**——而且特意声明与检测头那派"互补"，等于提前给"Swin 骨干 + DETR 头"这种组合留好了接口。

### 派系四：Transformer 视觉骨干网（同宗同源，竞争最激烈）

> *"While ViT requires large-scale training datasets (i.e., JFT-300M) to perform well, DeiT introduces several training strategies that allow ViT to also be effective using the smaller ImageNet-1K dataset. The results of ViT on image classification are encouraging, but its architecture is unsuitable for use as a general-purpose backbone network on dense vision tasks or when the input image resolution is high, due to its low-resolution feature maps and the quadratic increase in complexity with image size."*

**直译：** ViT 需要大规模训练数据集（即 JFT-300M）才能表现良好，DeiT 引入了若干训练策略使 ViT 在较小的 ImageNet-1K 数据集上也有效。ViT 在图像分类上的结果令人鼓舞，但由于其特征图分辨率低、复杂度随图像尺寸二次增长，其架构不适合在密集视觉任务或高分辨率输入下用作通用骨干网络。

**解读：** 对 ViT、DeiT 的点评精准呼应路线图：ViT 的两处病——**要私有大数据**（DeiT 已治）、**单一低分辨率特征图 + 二次复杂度**（本文来治）。对直接上采样硬做密集任务的 SETR 一系，评价是"能做但表现较次"；对同期改造 ViT 的并行工作（T2T、Bottleneck Transformer 等），则声明 Swin 在分类上的速度-精度权衡仍是最好的——**哪怕本文的重心根本不在分类**。最后补一刀针对另一篇同期多分辨率工作：你也是金字塔，但复杂度仍是二次的、注意力仍是全局的；本文线性且局部，而局部性"已被证明有利于建模视觉信号中的高相关性"。

## 二、方法 3.1：整体架构——四级组织是怎么搭起来的

### 原文（骨架描述）

> *"It first splits an input RGB image into non-overlapping patches by a patch splitting module, like ViT. Each patch is treated as a 'token' and its feature is set as a concatenation of the raw pixel RGB values. In our implementation, we use a patch size of 4 × 4 and thus the feature dimension of each patch is 4 × 4 × 3 = 48. A linear embedding layer is applied on this raw-valued feature to project it to an arbitrary dimension (denoted as C)."*

**直译：** 它首先像 ViT 一样，通过 patch 切分模块把输入 RGB 图像切成不重叠的 patch。每个 patch 被当作一个 "token"，其特征设为原始像素 RGB 值的拼接。在我们的实现中，patch 尺寸取 4 × 4，因此每个 patch 的特征维度为 4 × 4 × 3 = 48。一个线性嵌入层把这些原始值特征投影到任意维度（记为 C）。

**解读：** 起手与 ViT 完全同款，但有一个**关键数字差异：patch 尺寸 4×4（ViT 是 16×16）**。4×4 意味着起始分辨率是 H/4 × W/4，保留了足够细的底层信息，这是后面能接密集预测任务的前提——16×16 那种一上来就把图打稀的做法，像素级任务没法干。

### 原文（四个 Stage 的搭建）

> *"The Transformer blocks maintain the number of tokens (H/4 × W/4), and together with the linear embedding are referred to as 'Stage 1'. ... The first patch merging layer concatenates the features of each group of 2 × 2 neighboring patches, and applies a linear layer on the 4C-dimensional concatenated features. This reduces the number of tokens by a multiple of 2×2 = 4 (2× downsampling of resolution), and the output dimension is set to 2C. ... The procedure is repeated twice, as 'Stage 3' and 'Stage 4', with output resolutions of H/16 × W/16 and H/32 × W/32, respectively."*

**直译：** （Stage 1 的）Transformer 块保持 token 数量不变（H/4 × W/4），与线性嵌入层一起称为 "Stage 1"。……第一个 patch 合并层把每组 2 × 2 相邻 patch 的特征拼接起来，并对这 4C 维的拼接特征施加一个线性层。这使 token 数量变为原来的 2×2 = 4 分之一（分辨率 2 倍下采样），输出维度设为 2C。……该过程重复两次，作为 "Stage 3" 与 "Stage 4"，输出分辨率分别为 H/16 × W/16 与 H/32 × W/32。

**隐喻解读：** 组织架构四级成型：**Stage 1** 是全员基层（H/4 分辨率，C 维），只开会不合并；此后每个 Stage 入口处先来一次"4 人并 1 组长"（patch merging：2×2 拼接 → 线性层降维到 2C），token 数砍到 1/4，职权翻倍，再进若干 Swin 块开会。四级下来：H/4 → H/8 → H/16 → H/32，分辨率逐级减半、通道逐级翻倍（C → 2C → 4C → 8C）。

### 原文（与 CNN 对齐的深意）

> *"These stages jointly produce a hierarchical representation, with the same feature map resolutions as those of typical convolutional networks, e.g., VGG and ResNet. As a result, the proposed architecture can conveniently replace the backbone networks in existing methods for various vision tasks."*

**直译：** 这些 stage 共同产生层次化表示，其特征图分辨率与典型卷积网络（如 VGG 和 ResNet）相同。因此，所提架构可以便利地替换现有各类视觉方法中的骨干网络。

**解读：** 这句话是整个架构设计里最"务实"的一笔：**刻意把输出分辨率对齐成 ResNet 系的 {H/4, H/8, H/16, H/32}**。这样下游代码几乎不用改，把 backbone 一换就能跑检测/分割——"通用骨干网"的承诺要兑现，生态兼容性比什么都重要。

### Swin 块的内部接线

> *"A Swin Transformer block consists of a shifted window based MSA module, followed by a 2-layer MLP with GELU non-linearity in between. A LayerNorm (LN) layer is applied before each MSA module and each MLP, and a residual connection is applied after each module."*

**直译：** 一个 Swin Transformer 块由一个基于移位窗口的 MSA 模块、后接一个两层 MLP（中间用 GELU 非线性）构成。每个 MSA 模块和每个 MLP 之前各施加一个 LayerNorm（LN）层，每个模块之后各施加一条残差连接。

**解读：** 块内结构就是标准 Transformer 块的配方——Pre-LN、MLP 两层带 GELU、残差连接，**唯一的改动只有一处：把全局 MSA 换成基于移位窗口的 MSA**。改动极小、其余照旧，这正是它好复现、好移植的原因。两个连续的 Swin 块按式 (3) 配对工作：第一块用常规窗口 W-MSA，第二块用移位窗口 SW-MSA，MLP 部分完全相同。

## 三、方法 3.2：移位窗口自注意力——全文的技术核心

### 1. 先算账：全局 MSA vs 窗口 W-MSA

> *"Supposing each window contains M × M patches, the computational complexity of a global MSA module and a window based one on an image of h × w patches are:
> Ω(MSA) = 4hwC² + 2(hw)²C,   (1)
> Ω(W-MSA) = 4hwC² + 2M²hwC, (2)
> where the former is quadratic to patch number hw, and the latter is linear when M is fixed (set to 7 by default)."*

**直译：** 设每个窗口含 M × M 个 patch，则对一幅 h × w 个 patch 的图像，全局 MSA 模块与基于窗口的模块的计算复杂度分别为：Ω(MSA) = 4hwC² + 2(hw)²C；Ω(W-MSA) = 4hwC² + 2M²hwC。前者相对 patch 数 hw 是二次方的，后者在 M 固定（默认设为 7）时是线性的。

**解读：** 两条公式结构相同，拆开看：

| 项 | 来源 | MSA | W-MSA |
|---|---|---|---|
| 4hwC² | Q/K/V 投影 + 输出投影（线性层，随 token 数线性） | 相同 | 相同 |
| 第二项 | 注意力本体：QKᵀ 与 (分数)×V | **2(hw)²C**（全员两两配对） | **2M²hwC**（每个 token 只与窗口内 M² 个同伴配对） |

差别全在第二项：全局注意力里每个 token 要和 hw 个 token 算相似度，平方爆炸；窗口版里每个 token 只和同窗的 M² 个 token 算，M 固定则单 token 开销是常数，总量随 hw 线性增长。**默认 M = 7（49 个 patch 一个窗口）**——这就是"部门规模定死 49 人，公司扩编只是多开部门"的算术底稿。（Softmax 的开销在复杂度统计中被省略。）

### 2. 移位：部门重划怎么划

> *"The first module uses a regular window partitioning strategy which starts from the top-left pixel, and the 8 × 8 feature map is evenly partitioned into 2 × 2 windows of size 4 × 4 (M = 4). Then, the next module adopts a windowing configuration that is shifted from that of the preceding layer, by displacing the windows by (⌊M/2⌋, ⌊M/2⌋) pixels from the regularly partitioned windows."*

**直译：** 第一个模块使用常规的窗口划分策略，从左上角像素开始，8 × 8 的特征图被均匀划分为 2 × 2 个尺寸为 4 × 4 的窗口（M = 4）。随后，下一个模块采用相对前一层偏移的窗口配置，即窗口相对常规划分平移 (⌊M/2⌋, ⌊M/2⌋) 个像素。

**解读：** 移位量是**半个窗口**（M/2，向下取整）向右下。以正文示例：8×8 特征图、M=4，常规划分得 2×2 四个部门；移位后新划分从 (2,2) 处起划，新部门正好骑在旧部门的十字边界上——旧部门里互不相见的成员，在新部门里同桌开会，信息两轮即跨区。连续两层的计算按式 (3)：

```
ẑˡ   = W-MSA(LN(zˡ⁻¹)) + zˡ⁻¹     ← 常规窗口
zˡ   = MLP(LN(ẑˡ)) + ẑˡ
ẑˡ⁺¹ = SW-MSA(LN(zˡ)) + zˡ        ← 移位窗口
zˡ⁺¹ = MLP(LN(ẑˡ⁺¹)) + ẑˡ⁺¹
```

### 3. 工程难点：移位会切出碎窗口，怎么办？

> *"An issue with shifted window partitioning is that it will result in more windows, from ⌈h/M⌉ × ⌈w/M⌉ to (⌈h/M⌉ + 1) × (⌈w/M⌉ + 1) in the shifted configuration, and some of the windows will be smaller than M × M. A naive solution is to pad the smaller windows to a size of M × M and mask out the padded values when computing attention. When the number of windows in regular partitioning is small, e.g. 2 × 2, the increased computation with this naive solution is considerable (2 × 2 → 3 × 3, which is 2.25 times greater)."*

**直译：** 移位窗口划分的问题在于窗口数会增多，从 ⌈h/M⌉ × ⌈w/M⌉ 变成移位配置下的 (⌈h/M⌉ + 1) × (⌈w/M⌉ + 1)，且部分窗口会小于 M × M。一个朴素的解法是把小窗口填充到 M × M，并在计算注意力时掩掉填充值。当常规划分下窗口数较少时（如 2 × 2），这一朴素解法带来的额外计算相当可观（2 × 2 → 3 × 3，即 2.25 倍）。

**隐喻解读：** 重划部门听着美，执行起来有麻烦：网格一错半格，边缘上会切出一堆**不足编制的碎部门**。笨办法是给碎部门强行凑满编制（padding + mask）——浅层特征图大、窗口多时还好，到了深层只剩 2×2 个窗口，碎窗一补直接变 3×3，开销翻 2.25 倍，等于改革把行政成本改上去了。

### 原文（正解：循环移位 + 掩码）

> *"Here, we propose a more efficient batch computation approach by cyclic-shifting toward the top-left direction. After this shift, a batched window may be composed of several sub-windows that are not adjacent in the feature map, so a masking mechanism is employed to limit self-attention computation to within each sub-window. With the cyclic-shift, the number of batched windows remains the same as that of regular window partitioning, and thus is also efficient."*

**直译：** 我们提出一种更高效的分批计算方式：向左上方向做循环移位。移位后，一个批处理窗口可能由特征图中不相邻的若干子窗口组成，因此采用掩码机制，把自注意力计算限制在每个子窗口内部。借助循环移位，批处理窗口数与常规窗口划分保持一致，因而同样高效。

**隐喻解读：** 妙手在于**不动网格、只挪内容**：把整张特征图像传送带一样向左上循环卷动半格，网格线不动，于是窗口数量一个不多、一个不少；代价是卷动后有些窗口里混进了来自地图两端的"陌生人"——给这些不相邻的子窗口之间拉上帘子（mask，注意力分数置 −∞），开会时互不理睬即可。效果等价于移位划分，开销却与常规划分完全相同（低延迟见表 5）。这是"理论上同一件事，工程实现决定成败"的又一例。

### 4. 相对位置偏置：座位表也有讲究

> *"In computing self-attention, we follow ... by including a relative position bias B ∈ R^{M²×M²} to each head in computing similarity:
> Attention(Q, K, V) = SoftMax(QKᵀ/√d + B)V,   (4)
> ... Since the relative position along each axis lies in the range [−M+1, M−1], we parameterize a smaller-sized bias matrix B̂ ∈ R^{(2M−1)×(2M−1)}, and values in B are taken from B̂."*

**直译：** 计算自注意力时，我们沿袭已有做法，在计算相似度时为每个头加入一个相对位置偏置 B ∈ R^{M²×M²}：Attention(Q, K, V) = SoftMax(QKᵀ/√d + B)V。……由于每个轴上的相对位置取值范围为 [−M+1, M−1]，我们参数化一个更小的偏置矩阵 B̂ ∈ R^{(2M−1)×(2M−1)}，B 中的值从 B̂ 中取。

**解读：** 注意力分数在 QKᵀ/√d 之外**加上**（不是乘、不是拼接）一张可学习的"相对座位表"：谁坐在谁旁边几行几列，对应一个可训练偏置。两个工程细节值得记：

1. **压缩参数化**：M² 个 token 两两之间的相对位置其实只有 (2M−1)² 种（每轴 −M+1 到 M−1），所以真正要学的只是这张小表 B̂，用时再展开成 B。M=7 时从 49×49=2401 项压缩到 13×13=169 项。
2. **消融结论（表 4，第 3 站细讲）**：相对位置偏置比"无偏置"和"绝对位置嵌入"都显著更好；**再叠加 ViT 式的绝对位置嵌入反而略降**，故不采用。此外预训练学到的 B̂ 可以双三次插值后用于不同窗口尺寸的微调初始化——位置知识可迁移。

## 四、方法 3.3：架构变体——四档组织规模

> *"We build our base model, called Swin-B, to have of model size and computation complexity similar to ViT-B/DeiT-B. We also introduce Swin-T, Swin-S and Swin-L, which are versions of about 0.25×, 0.5× and 2× the model size and computational complexity, respectively. Note that the complexity of Swin-T and Swin-S are similar to those of ResNet-50 (DeiT-S) and ResNet-101, respectively."*

**直译：** 我们构建基础模型 Swin-B，使其模型规模与计算复杂度与 ViT-B/DeiT-B 相近。另引入 Swin-T、Swin-S 与 Swin-L，分别约为 0.25 倍、0.5 倍与 2 倍的模型规模与计算复杂度。注意 Swin-T 与 Swin-S 的复杂度分别与 ResNet-50（DeiT-S）、ResNet-101 相近。

**解读：** 四档超参数：

| 变体 | 通道数 C | 各 Stage 块数 | 对标 |
|---|---|---|---|
| Swin-T | 96 | {2, 2, 6, 2} | ResNet-50 / DeiT-S |
| Swin-S | 96 | {2, 2, 18, 2} | ResNet-101 |
| Swin-B | 128 | {2, 2, 18, 2} | ViT-B / DeiT-B |
| Swin-L | 192 | {2, 2, 18, 2} | 约 2× Swin-B |

全体实验统一：窗口大小 M = 7、每头 query 维度 d = 32、MLP 扩展比 α = 4。**扩规模的方式是加深（Stage 3 从 6 块加到 18 块）加加宽（C 从 96 到 192）**，四档锚定在既有模型的 FLOPs 档位上——又是"相近计算量下比精度"的公平对照思路，第 3 站的实验全靠这个前提。

## 五、小结

| 要点 | 内容 |
|---|---|
| 相关工作四派 | CNN 正统 / 滑窗注意力换卷积（输在延迟）/ 注意力给 CNN 打下手（互补）/ ViT 系骨干（本文直面对手） |
| 整体架构 | patch 4×4 起步 → 线性嵌入 → 四个 Stage：W/SW-MSA 块交替 + 三次 patch merging（2×2 拼接→线性层，token ÷4、通道 ×2） |
| 与生态对齐 | 四级分辨率 {H/4, H/8, H/16, H/32} 与 ResNet 系一致，骨干即插即换 |
| 复杂度 | Ω(MSA) = 4hwC² + 2(hw)²C（二次）→ Ω(W-MSA) = 4hwC² + 2M²hwC（M 固定则线性），差别全在注意力本体项 |
| 移位实现 | 半窗移位 (⌊M/2⌋, ⌊M/2⌋)；碎窗口问题用**向左上循环移位 + 子窗口掩码**解决，窗口数不增 |
| 位置编码 | 相对位置偏置 B（由 (2M−1)² 小表 B̂ 展开），加在注意力分数上；优于绝对嵌入，且可插值迁移 |
| 变体策略 | T/S/B/L 四档，块数与 C 联动扩缩，全部锚定既有模型的 FLOPs 档位 |

**式 (3) 两层块的"呼吸节奏"：**

```
第 l 层：  W-MSA（常规划分：各开各的部门会）→ MLP
第 l+1 层：SW-MSA（半窗移位：重划部门，跨界流通）→ MLP
第 l+2 层：W-MSA（回到常规，但信息已过两轮桥）→ …
```
