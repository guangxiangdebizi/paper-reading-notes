## 一、结论（§5）：四句话收束全文

> *"This paper presents Swin Transformer, a new vision Transformer which produces a hierarchical feature representation and has linear computational complexity with respect to input image size. Swin Transformer achieves the state-of-the-art performance on COCO object detection and ADE20K semantic segmentation, significantly surpassing previous best methods."*

**直译：** 本文提出 Swin Transformer，一种产生层次化特征表示、且相对输入图像尺寸具有线性计算复杂度的新视觉 Transformer。Swin Transformer 在 COCO 目标检测与 ADE20K 语义分割上取得最先进性能，显著超越此前最佳方法。

**解读：** 结论第一句把两处病灶的药方复述一遍（层次化 + 线性复杂度），第二句把成绩单亮出来——注意炫的依然是检测与分割这两个密集战场，而不是分类。

> *"We hope that Swin Transformer's strong performance on various vision problems will encourage unified modeling of vision and language signals. As a key element of Swin Transformer, the shifted window based self-attention is shown to be effective and efficient on vision problems, and we look forward to investigating its use in natural language processing as well."*

**直译：** 我们希望 Swin Transformer 在各类视觉问题上的强劲表现，能推动视觉与语言信号的统一建模。作为 Swin Transformer 的关键要素，基于移位窗口的自注意力已被证明在视觉问题上既有效又高效，我们也期待研究它在自然语言处理中的使用。

**解读：** 结尾两处展望值得记住：一是重申"视觉-语言统一建模"的愿景（与引言收尾呼应，为多模态时代埋桩）；二是**想把移位窗口搬回 NLP**——组织改革方案反过来输出给语言公司。这句"从 NLP 来、回 NLP 去"的闭环姿态，是整篇论文格局的最后一笔。

## 二、附录精华

### A1 完整架构表（Table 7）里的一眼细节

Table 7 把四个变体的逐 stage 规格列全（输入 224²）：stage 1 输出 56×56、stage 2 28×28、stage 3 14×14、stage 4 **7×7**。除通道与深度外，有两个数字值得留意：

1. **patch 划分写的是 "concat 4×4"**——印证正文：Swin 的 patchify 本质是"4×4 相邻像素拼接 + 线性层"，与 ViT 的 16×16 步长卷积等价但起点细 16 倍（面积）。
2. **stage 4 的特征图恰好 7×7，而默认窗口尺寸也是 7×7**——也就是说，最深层的那一次"部门会议"恰好是**全员大会**（一个窗口装下整张特征图）。Swin 在顶层悄悄恢复了全局注意力，只不过此时 token 只剩 49 个，开销九牛一毛。层级结构把昂贵的全局交互推迟到信息最浓缩的那一层——这是架构里一笔没写进正文的巧思。

### A2 训练细节中的两处发现

**发现一：分类不用 class token，用全局平均池化。**

> *"The image classification is performed by applying a global average pooling layer on the output feature map of the last stage, followed by a linear classifier. We find this strategy to be as accurate as using an additional class token as in ViT and DeiT."*

**直译：** 图像分类通过在最后一个 stage 的输出特征图上施加全局平均池化层、后接线性分类器来完成。我们发现这一策略与 ViT、DeiT 那样使用额外的 class token 同样精确。

**隐喻解读：** 年终总评不再专设一个"董事长秘书"（CLS token）去汇总全公司意见，直接把所有员工的考核表取平均——效果一样。这一笔在主线 D（Registers / LAST-ViT）的视角下格外有趣：Swin 早早绕开了 CLS token，而三年后的研究恰恰发现 CLS token 的聚合行为有毛病（懒惰聚合、背景污染）。此处不展开，留作后续阅读时的对照点。

**发现二：DeiT 的 repeated augmentation 与 EMA 在 Swin 上不需要**（正文 §4.1 已述，附录确认）。层级 + 局部窗口带来的归纳偏置让优化更容易稳定，配方可以减负。

### A3.1 输入分辨率缩放（Table 8）

Swin-T/S/B 从 224² 放大到 384²：Swin-T 81.3→82.2，Swin-S 83.0→83.9，Swin-B 83.5→84.5。**更大输入换来更高精度、更慢吞吐**，且高分辨率模型由 224² 版本微调而来（而非从头训练）以省 GPU。线性复杂度在这里显出实用价值：放大输入的代价是线性上涨的，ViT 式二次复杂度架构在高分辨率下的成本曲线要陡得多。

### A3.2 给 CNN 对手也换好装备（Table 9）

> *"While SGD is used as a default optimizer for Cascade Mask R-CNN framework, we generally observe improved accuracy by replacing it with an AdamW optimizer, particularly for smaller backbones. We thus use AdamW for ResNe(X)t backbones when compared to the proposed Swin Transformer architectures."*

**直译：** Cascade Mask R-CNN 框架的默认优化器是 SGD；我们发现将其替换为 AdamW 通常能提升精度，对小骨干网尤其如此。因此在与 Swin Transformer 架构对比时，ResNe(X)t 骨干网也使用 AdamW。

**解读：** 这是实验公平性的一块暗补丁：检测场上 ResNe(X)t 的成绩**已经是换上 AdamW 后的加强版**（如 R50 从 45.0 涨到 46.3 box AP）。Swin 对 CNN 的领先是在"给对手发好装备"之后取得的，含金量反而更高。论文写作上这也是一种防御性诚实——把可能被人质疑的点先自己说出来。

### A3.3 Swin-Mixer：组织方案输出给 all-MLP 架构（Table 10）

> *"Swin-Mixer performs significantly better than MLP-Mixer (81.3% vs. 76.4%) using slightly smaller computation budget (10.4G vs. 12.7G). It also has better speed accuracy trade-off compared to ResMLP. These results indicate the proposed hierarchical design and the shifted window approach are generalizable."*

**直译：** Swin-Mixer 以略小的计算预算（10.4G 对 12.7G）显著优于 MLP-Mixer（81.3% 对 76.4%），并且相比 ResMLP 有更好的速度-精度权衡。这些结果表明所提的层次化设计与移位窗口方案是可泛化的。

**隐喻解读：** 把这套"部门划分 + 定期重划部门 + 逐级设管理层"的组织方案原样搬给一家不用"注意力"工艺的公司（all-MLP 的 MLP-Mixer），业绩照样大涨——说明真正值钱的不是注意力本身，而是**窗口的组织方式**。这与 ConvNeXt 从另一面得出的结论（配方与设计占大头）隔空咬合：2021–2022 年的两篇论文，一篇说"组织方式搬到纯 MLP 也赢"，一篇说"配方搬到纯 CNN 也赢"，共同把"架构的宏观组织与设计"推上功劳簿。摘要末尾那句"移位窗口对 all-MLP 架构同样有益"的出处即在此。

## 三、全文收官总表

| 维度 | Swin 的答案 |
|---|---|
| 立题 | ViT 只能分类、二次复杂度，接不了密集预测；要把它改造成通用骨干网 |
| 病灶一 → 药方 | 尺度多变 → **patch merging 层级化**（四级特征图，对齐 ResNet 分辨率） |
| 病灶二 → 药方 | 高分辨率 × 二次复杂度 → **窗口内局部自注意力**（M=7 固定，复杂度线性） |
| 补漏 → 药方 | 窗口间失联 → **移位窗口**（半窗平移；循环移位 + 掩码实现，碎窗不增开销） |
| 位置编码 | 相对位置偏置独用最优；绝对嵌入害密集任务 |
| 战绩 | ImageNet 87.3（Swin-L 22K）；COCO 58.7/51.1（+2.7/+2.6 SOTA）；ADE20K 53.5（+3.2 SOTA） |
| 规律 | 任务越密集，Swin 相对 ViT/DeiT 优势越大（分类 +1.5 → 检测 +3~4 → 分割 +5.3） |
| 泛化 | 组织方案输出给 all-MLP（Swin-Mixer）照样赢；移位窗口甚至想回输 NLP |
| 生态 | 代码模型全开源；骨干即插即换（对齐 ResNet 分辨率 + mmlab 全家桶验证） |
