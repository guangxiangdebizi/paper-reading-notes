# Registers 精读笔记 01：摘要与引言——问题是怎么发现的

> 论文：**Vision Transformers Need Registers**  
> ICLR 2024 · arXiv:2309.16588v2  
> 本站对应原文摘要、§1、§2.1 开头；关键图：`../figures/page_1.png`、`../figures/page_2.png`、`../figures/page_3.png`

## 一、先修正路线图里的一句话

路线图里的“模型拿高范数垃圾 token 当垃圾桶”抓住了直觉，但精读时应改成更准确的表述：

1. **它们不是额外生成的垃圾 token**，而是原本与真实图像位置一一对应的 patch token；
2. **它们不是没有信息**：线性探针显示它们丢失了原 patch 的位置和像素信息，却比普通 patch 含有更多图像级分类信息；
3. **“垃圾桶”只是作者对功能的解释，不是直接观测到的事实**。直接证据是：范数离群、常出现在冗余背景、局部信息少、全局信息多；据此作者推断模型把这些 token 复用成了内部计算的临时存储空间；
4. register token 也不是把“垃圾”删除，而是给同一种内部计算行为提供一个**不占用空间 patch** 的合法位置。

因此本文的准确主线是：

```text
密集特征/注意力图出现尖锐 artifact
  → 定位到少量 high-norm patch token
  → 证明它们局部信息少、全局信息多
  → 推断 patch token 被复用为内部寄存器
  → 显式加入 register token
  → high-norm 行为迁移到 registers，patch 特征图恢复平滑
```

## 二、摘要逐句精读

### 原文 1：问题不是 DINOv2 独有

> *"In this paper, we identify and characterize artifacts in feature maps of both supervised and self-supervised ViT networks."*

**直译：** 本文识别并刻画了监督与自监督 ViT 网络特征图中的 artifact。

**解读：** 作者最初是从 DINOv2 的异常行为开始调查，但 Fig. 2 把范围扩展到三种训练范式：

- 标签监督：DeiT-III；
- 文本监督：OpenCLIP；
- 自监督：DINO、DINOv2。

除 DINO-v1 外，其余展示的现代 ViT 都有尖锐离群响应。因此论文的重要转折不是“DINOv2 有 bug”，而是：**DINO-v1 的干净注意力图可能才是例外，artifact 更接近大规模 ViT 的常见行为。**

### 原文 2：artifact 的可测定义

> *"The artifacts correspond to high-norm tokens appearing during inference primarily in low-informative background areas of images, that are repurposed for internal computations."*

**直译：** 这些 artifact 对应推理时主要出现在图像低信息背景区域的高范数 token；这些 token 被重新用于内部计算。

**解读：** 这句话包含“观测”和“解释”两层，不能混在一起：

| 层次 | 内容 | 证据性质 |
|---|---|---|
| 观测 | 输出 patch token 的 L2 范数呈双峰；少数 token 是离群值 | 直接测量 |
| 观测 | high-norm token 常落在与邻域相似的均匀背景 | 输入 patch 邻域相似度 + 可视化 |
| 观测 | 它们的局部位置/像素信息更少，但图像分类信息更多 | 线性 probing |
| 解释 | 模型主动识别冗余 patch，并把对应 token 改作全局内部计算空间 | 作者假设 |

本文后续所有实验都围绕这四格展开。尤其要记住：**high norm 是检测信号，不等于根因本身。**

### 原文 3：解法

> *"We propose a simple yet effective solution based on providing additional tokens to the input sequence of the Vision Transformer to fill that role."*

**直译：** 作者提出一个简单而有效的方案：向 ViT 输入序列提供额外 token，让它们承担该角色。

**解读：** 在 patch embedding 之后加入若干可学习向量，形式上与 CLS token 类似：

```text
原模型： [CLS] [P1] [P2] ... [PN]
修改后： [CLS] [R1] [R2] ... [RK] [P1] [P2] ... [PN]
```

`R1...RK` 不编码输入图像内容，输出也不交给下游任务；它们只参与各层 self-attention，供模型写入、读取和处理中间信息。论文默认 `K=4`。

这里最漂亮的研究逻辑是：**解法本身也是因果探针。** 如果模型确实只因缺少专用计算空间才占用 patch token，那么提供专用 token 后，离群行为应从 patch 上消失并转移到 registers；附录 Fig. 15 与 Table 4 正是这个验证。

## 三、引言：论文是从什么反常现象出发的

### 原文 4：DINOv2 明明强，却不能接好 LOST

> *"Despite the strong performance on dense tasks, we observed that DINOv2 is surprisingly incompatible with LOST."*

**直译：** 尽管 DINOv2 在密集任务上表现很强，作者却观察到它与 LOST 出人意料地不兼容。

**解读：** 这是全文真正的起点。DINO-v1 的最后层注意力能够自然突出物体，LOST 因而可在无标签条件下定位目标；DINOv2 在冻结骨干 + 线性头的分割、深度估计上更强，但把它的局部特征直接交给 LOST，表现却只相当于监督骨干。

这不是矛盾，因为两类评估要求不同：

- 线性分割/深度头可以学习如何过滤特征中的异常维度；
- LOST 直接依赖局部特征的平滑性和相似度结构，没有训练出来的过滤器兜底。

所以 aggregate benchmark 变好，不代表裸 patch feature map 的几何结构一定更干净。

### 原文 5：异常的数量级与出现条件

> *"We observe that they are tokens with roughly 10x higher norm at the output and correspond to a small fraction of the total sequence (around 2%)."*

**直译：** 作者观察到，这些 token 在输出处的范数约高 10 倍，只占总序列的一小部分（约 2%）。

**解读：** 在 DINOv2 ViT-g/14 的示例统计中，普通 patch token 范数大多位于 `0–100`，作者以 `150` 为该模型的人工阈值，测得 `2.37%` 的 token 超阈值。阈值不是通用常数，换模型需要根据其范数分布重新定。

作者还给出三条出现条件：

1. 在 40 层 ViT-g 中，离群 token 大约从第 15 层开始与普通 token 分离；
2. 约训练到全程三分之一后才出现；
3. DINOv2 的 Tiny/Small/Base 没有明显离群，Large/Huge/giant 才出现。

因此不能把结论粗暴扩写成“任何 ViT 天生都有 high-norm token”。论文支持的是：**模型足够大、训练足够久时更容易涌现；不同预训练范式还会改变出现门槛。** DeiT-III 和 OpenCLIP 在 Base/Large 就已经出现离群，作者并未完全解释原因。

## 四、全文论证合同：作者到底需要证明什么

要让“ViT 需要 registers”成立，至少要连续通过五道门：

| 门 | 待证明命题 | 对应证据 |
|---|---|---|
| 1. 现象 | 尖锐响应不是纯可视化错觉 | 输出 token 范数双峰、约 2.37% 超阈值 |
| 2. 定位 | artifact 确实由少数 patch token 导致 | 范数图、注意力图、PCA 特征图相互对应 |
| 3. 功能 | 它们不再主要表示原位置 | 位置预测与像素重建显著变差 |
| 4. 复用 | 它们承担了全局信息聚合 | 单个 outlier token 的分类 probing 远强于普通 patch |
| 5. 干预 | 专用 token 能隔离这一行为并改善下游 | patch 离群消失；register 接走高范数/全局信息；分割、深度、LOST 改善 |

这也是后面三站的阅读顺序。只看 Fig. 1 的“前后变干净”最多证明第 5 门的一部分；本文真正有价值的是前四门把一个视觉现象变成了可检验的表示行为假设。

## 五、本章小结

| 维度 | 结论 |
|---|---|
| 触发问题 | DINOv2 的线性密集预测很强，却明显破坏直接依赖局部特征平滑性的 LOST |
| artifact | 少量 patch 位置出现尖锐响应；可用输出 patch token 的 L2 范数离群进行检测 |
| 规模 | 示例中约 10× 范数、2.37% token；数值阈值依模型而变 |
| 出现条件 | DINOv2 中约从中层、训练三分之一后、ViT-L 及以上出现；跨训练范式的门槛不同 |
| 关键修正 | outlier token 不是“无信息垃圾”，而是**局部信息被全局计算功能替换**的 patch token |
| 核心假设 | 模型识别低信息冗余 patch，把对应 token 复用为全局内部计算空间 |
| 干预 | 加入不承载输入、输出时丢弃的可学习 register token，为该计算行为提供专用位置 |
| 尚未回答 | 为什么某些训练目标/规模会诱发这种行为；为何 DINO-v1 与 MAE 没有明显 artifact |

### 自检小问题

1. 为什么“high-norm token = 垃圾 token”不准确？它丢了什么信息，又多了什么信息？
2. DINOv2 的分割/深度线性评估很强，为什么仍可能让 LOST 退化？
3. 论文直接观测到的是“模型把 patch 当寄存器”，还是从多项观测推断出的解释？
4. 为什么“加入 register 后 high-norm patch 消失”不仅是修复效果，也是对机制假设的一次干预验证？
5. 这篇论文是否证明所有 ViT、所有训练阶段都会出现 high-norm artifact？
